## 2026-10-02（CHAT-1002-DOJ-03）

- 月中にゲスト予定が変わったら、カレンダーを更新のうえ通知する。実行時点より過去の変更は対応しない（#390）
- 書き込み済みの月の画像が差し替わったら、毎朝の定期実行がカレンダーを自動で更新し、#426 に通知する。新しい月の初回は今までどおり、通知を見てから手動で書き込む（2026-10-02〈CHAT-1002-DOJ-01〉の「定期実行の自動書き込みは見送る」を、月中の変更に限って置き換える）
- 更新するのは実行した日（日本時間）以降の日だけ。当日を含む。前日までは触らない
- ゲストが替わった日は予定の名前と X の URL を書き換える。無くなった日（休みなど）は削除する。増えた日は足す
- 書き換え・削除は同期が作った予定（目印付き）だけ。手で入れた予定は変えず、食い違いは通知に書く
- 安全弁: 照合できない名前が1件でもあるとき、変更が3件以上のときは自動更新せず通知だけにし、確かめてから手動実行で反映する
- テストが通れば cloudflare へマージしてよい
