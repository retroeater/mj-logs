## 2026-11-03（CHAT-1103-RYO-04）

- 連盟プロと重なる内容を消す: 名前の面のチップ（所属・入会期）、自己紹介の鳳凰戦・段位、数字で見るの連盟プロの人数、成績の面、入賞の面（段位〈名簿〉・入賞〈title/ のデータ〉の仕組みもあわせて外す）（#657）
- 「連盟プロ」のカードの形でなく、経歴・ポートフォリオを1枚で見せる LP の形にする。アニメーションとインタラクティブ性を駆使して尖ったページにする（r/ は「新サイトの基本の形」の例外）
- スマホの一人称視点で空間を歩き回る。コンテンツが空間に点在し、映画館では出演作を見せ、近づく（触れる）と視聴・閲覧できる。平野の半生の一場面を覗き見るような、誰もいない記憶の中の世界
- 絵柄は線画に近く実写との間のアニメーションの方向性（作品の場面・人物は写さない）。移動の足音・風・空気・水の音を付ける。メニューから場所へ直接行ける
- 3D は Three.js をリポジトリに置いて使う（CDN は使わない。新しい依存として承認）。置き場所は `assets/vendor/three-0.169.0/`（版はパスに入れる。読むのは r/ だけ。更新は版を変えて別のパスに置き直す）
- 絵は 3D の形に輪郭線と平塗りの陰影でコードで描く。人生の場面には平野さんの写真を線画・減色に加工したパネルを置く（試作では写真を使わない）
- 動画は空間の中で YouTube の埋め込みで再生する。`_headers` の CSP の `frame-src` に `https://www.youtube-nocookie.com` を許す（それまでは `'none'`）
- 音はブラウザの中で合成する（Web Audio。外部の音声ファイルは使わない）。最初の「入る」で音ありで始め、いつでも消せる
- 試作は「映画館（出演7本）」と「対局室（麻雀卓と牌）」の2場面。平野さんが iPhone で触ってから残りの場面を足す
