# WRC リーグの新ページ `jwrc/`（houou/・ouka/ との違い）

WRC リーグの成績とランキング（旧 `wrc_results.html`・`wrc_ranking.html`）を、鳳凰戦の `houou/`（`docs/notes/houou-top.md`）・女流桜花の `ouka/`（`docs/notes/ouka-top.md`）と同じ作りで `jwrc/` に作る（#594。案C の WRC 側、#141）。
**ここには houou/・ouka/ と違うことだけを書く。** 書いていないこと（画面・部品・数え方・確かめ方・字の大きさへの連動・在籍者だけ・名寄せ）は houou-top.md と ouka-top.md のとおり（ouka/ が houou/ から変えた所〈大会ごとの設定・最近見た選手のキー・質問欄の大会・通期の期〉は ouka/ に倣う）。
未公開（段1、全ページ noindex・navbar／サイトマップ／`llms.txt` に載せない）で、公開は #599。URL は本家の世界麻雀（World Riichi Championship）と混ざらないよう `jwrc/`（2026-10-18）。

## 構成と生成

- URL: `jwrc/`（トップ・質問欄）・`jwrc/players/`・`jwrc/ranking/<スラッグ>/`（9部門。`jwrc/ranking/` は `total/` へ 301）・`jwrc/race/`
- 生成は `scripts/generate_jwrc_pages.py`（`regenerate.py` の `jwrc_pages`、出力 `jwrc/`）。中身は `generate_houou_pages.py` を大会の設定 `JWRC` で動かすだけ。`Contest.no_leagues`（リーグの列が無い大会）で、リーグ・リーグのタブ・現在のリーグに頼る所を外す
- JS は houou/・ouka/ と共有の `assets/league.js`・`assets/league_race.js`・`assets/houou_ask.js`。ページの `#league_contest`（`JWRC.script`）の `noLeagues`・`pass`・`championLabel` で動きを替える
- 集計元は正本の「JWRC」タブ（見出しで読む。名前・期・順位・結果・合計・第1〜5節・表示・備考の12列）。「表示」が Y の行の数が 1,000〜4,000 の外なら止める（`JWRC.rows`）。Ampai のブックは読まない（`JWRC.ampai` が空）
- 質問欄の検索データは `workers/ask/data-jwrc.json`（`scripts/generate_ask_data_jwrc.py`、`regenerate.py` の `ask_data_jwrc`）

## データの違い

- リーグ・前期後期・昇降級・組が無い。全行を1つのリーグ「予選」（`JWRC_LEAGUE`）の通期として扱う（成績 JSON の前後は 0・リーグは「予選」、順位変動の期のキーは `<期>-0`、URL は `jwrc/race/?term=19`）
- 「結果」は通過・敗退だけ。通過はこの予選（JWRC タブの順位）で通過の範囲に入った人で、トーナメントに出た経路は問わない（第14期 予選29位 川上直也は関西予選から出たが「通過」）。予選で通過せず地方予選などからトーナメントに出た人は「敗退」（第19期 予選55位 小川尚哉、2026-10-18。docs/decisions/houou.md・operations.md の 2026-10-18）
- 節は第1〜5節。途中敗退の選手は節が途中で切れる（順位変動では「第n節まで」）
- 進行中の期（第20期）は「JWRC」タブに行が入ったら、houou/ と同じく期別の先頭に出す（「表示」が N の行。2026-10-18 に確定）。行のリンクは Ampai の代わりに公式の成績表（`JWRC.result_urls` の期の URL、無い期は大会のページ `JWRC.result_index`。2026-10-18）。**期が変わったら `result_urls` に次の期の成績表の URL を足す**（#365 の次の期の手順）。シード選手は予選に出ないので行が無い

## 画面の違い

- 文言は大会名を「WRCリーグ」にしたもの（title は「<ページ> | WRCリーグ | 日本プロ麻雀連盟 | ryoei.pro」、#523 で「JPML」を外した名前）。トップの3項目の説明は「選手ごとの期別・通算・最高到達」「通算・通過率など9部門」「期ごとの節単位の予選の順位」。質問欄の例は「例：19期の予選1位は？」
- 個人成績のタブは 期別・通算・部門別の3つ（「順位」のタブは 2026-10-18 に消した。旧い `?view=rank`・`?view=league` は期別で開く）
- 期別のカードにリーグの欄は無く、結果のチップは「通過」が金（地 `#f2c230`・字 `#2b2100`）・「敗退」が灰色（`--mj-n-line` の地に `--mj-n-muted` の字）。最強戦の結果のピル（`.mj-saikyo-n-pill`）と同じ色（2026-10-18）
- 名前の面: リーグのチップは無い。2行目「最高到達 優勝 2回（12期・11期）」、3行目「出場 15期（通過11回）」（2026-10-18。質問欄の選手のカードも同じ2つ）
- 最高到達（2026-10-18）: 「優勝」「2位」「3位」「4位」「予選通過」の5段（「予選通過」は 2026-10-18 に「トーナメント進出」から改名）。優勝〜4位は「タイトル」タブの決勝の順位（大会名「JPML WRCリーグ」、#523 の後の「WRCリーグ」も受ける。「表示」が Y の行。名前は「別名」で今の登録名に。予選に出なかった期〈シード〉の決勝も入る）、無ければ「JWRC」タブの「結果」の通過（予選通過）。いちばん上の段だけを、回数と、その段に届いた期を新しい期から3期まで（4期以上は「等」）付けて出す（例「予選通過 5回（19期・14期・9期 等）」、2026-10-18 の決定）。届いていなければ2行目を出さない。生成時に成績 JSON の `best` に入れる（`best_reach()`・`load_finals()`）。ベスト16・ベスト8 は扱わない（別の課題）
- 最近見た選手は localStorage の `mj:recent-players:jwrc`。履歴が無いときの1件は現タイトルホルダー（「タイトル」タブの最新の期の WRC リーグの優勝者、`title_holder()`。2026-10-18 は紺野真太郎）、印は「現タイトルホルダー」。予選に一度も出ていない人なら成績の行の無い選手として載せる（名前の面はアイコン・名前・最高到達、期別・通算・部門別は「データがありません」）。在籍していなければ1件を出さない（仮置き）
- 検索の候補の右端は「19期 通過」（リーグの代わりに最後の期の結果）
- ランキングの9部門: 通算・期平均・期最高・通過回数（`pass-count/`）・通過率（`pass-rate/`）・連続通過（`pass-streak/`）・節最高・節浮き率・節連続浮き（鳳凰戦の期浮き率・期連続浮き・連続昇級を置き換え、2026-10-18）。`lib/ranking.py` の `PASS_DIVISIONS`
  - 通過回数: 「結果」が通過の期の数（0回の選手は載せない）。値は「11回」
  - 通過率: 通過の期の数 ÷ 出場期数（合計のある行の数）。規定は期数（出場5期以上）。同じ率は出場期数の多い順。値は「0.733」
  - 連続通過: 続けて通過した期の数。出場しなかった期（行の無い期）で途切れる。値は「6期」
- 規定（出場の下限）は旧 `wrc_ranking.html` の値: 期平均・通過率は5期以上、節浮き率は25節以上（`CONTESTS["JWRC"]`）。表示対象は houou/ と同じ自動ルール
- 順位変動: 選ぶシートは期だけ（リーグ・前期後期の行は無い）、題名は「第19期 ▾」。帯は「通過ライン」1本（その期の通過者の数の位置）。ラインより下で通過の選手の印は置かない（2026-10-18 に消した。通過は予選の順位で決めるので、ラインより下の通過は出ない）
- OGP は `img/ogp/jwrc/index-white.png`（白地・黒字の「WRCリーグ」＋「ryoei.pro」、docs/notes/ogp.md の規則。2026-10-18 に確定）

## 質問欄

- Worker `mj-ask` と1日の上限を鳳凰戦・女流桜花と共有する。jwrc/ の質問欄は問いに `contest: "jwrc"` を添え、Worker は `data-jwrc.json` と `ask.mjs` の `JWRC_PLAN_SYSTEM`（リーグは「予選」だけ、部門は `JWRC_DIVISIONS`）で答える。記録の型は「jwrc:league」の形
- 決勝は title/search.json の「WRCリーグ」、放送対局は /live の「WRCリーグ」。時点は「WRCリーグ 第19期終了時点」（`query.mjs` の `leagueName()` は名前が「リーグ」で終わるとき「リーグ」を重ねない）

## 確かめ方

houou-top.md・ouka-top.md の「確かめ方」に加えて:

- ランキングの6部門（通算・期平均・期最高・節最高・節浮き率・節連続浮き）は、旧 `wrc_ranking.html`（Google Charts）の表から在籍者でない選手を除いて順位を付け直すと一致する。違いは同じ値の並び（新は名前の順）と、旧の件数の上限（新は自動ルール）だけ（2026-10-18、#594）
- 通過の3部門は「JWRC」タブから別に数えた上位10人と一致する
