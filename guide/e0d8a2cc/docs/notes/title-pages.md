# タイトル戦の新構成（title/ 配下、#222）

仕様の正本は #222 の本文。ここには実装の仕組みと、データの取り込み・運用で知っておくことを置く。

## ページと生成

- 扱うのは「タイトル戦」タブの区分=連盟 かつ 状態=継続 の大会だけ（CHAT-0916-TT-11）。それ以外の大会はページを作らず、
  「この選手の他のタイトル・決勝進出」・歴代・入口・`sitemap-title.xml` にも出さない。区分・状態を変えて再生成すると、
  非表示になった大会のページは `title/` から削除される。非表示の大会の数と行数は生成の出力に出る
- 表示する大会でも「タイトル」タブに表示=Y の行が無い大会（記録の無い大会）は、ページ・入口・sitemap に出さず、大会名を生成の出力に出す。記録が入れば次の生成で自動で出る（CHAT-0916-TT-15）。
  大会の追加・表示順・区分・状態は「タイトル戦」タブで管理する
- `scripts/generate_title_pages.py`（`regenerate.py` の `OUTPUT_OVERRIDES` は `"title/"`）が次を書き出す
  - `title/index.html`（入口: 現在のタイトルホルダー）
  - `title/<slug>/index.html`（大会ページ）
  - `title/<slug>/<期>.html`（期ページ。期は「期」列の数字。麻雀最強戦は `21.html` と `2021.html` が並ぶ）
  - `sitemap-title.xml`（全ページ。公開までは `sitemap.xml` から参照しない）
  - `title/search.json`（全ページの検索のデータ、#364）
- `render_content()` 方式。画像の読み込み失敗は `assets/title.js` が `data-fallback`（アバター）へ差し替える
- CSS は `style.css` の「タイトル戦(title/、#222)」節。クラスは `.mj-title*` と `body:has(.mj-title)` に閉じる
- 当面は `<meta name="robots" content="noindex">`。navbar・`llms.txt`・`sitemap.xml` には載せない
- 写真カードの処理は `generate_saikyo_pages.py` と重複している（共通化は #222 の未決定）
- 入口（#358・#364、2026-09-18）: タイトルホルダーを決勝日（日付列）の降順に並べ、カード全体を大会ページへのリンクにする。カードは写真そのもので、
  上端に大会名を帯（色は下の「帯と回戦ラベルの色」）で、下端に選手名を透明になるグラデーションに白文字と影で重ねる（#364。#358 の「大会名の帯と写真を縦に並べる」形はやめた）。
  大きさ・写真の値は最強戦の写真カード（`.mj-saikyo-card`）を `.mj-title-holder*` に写したもの（`.mj-saikyo*` は流用しない）。列は最小幅160px・最大4列。見出しと大会一覧・案内文は無く、h1 は読み上げ用に残す（案内文は CHAT-0918-TP-11 で削除）
- 大会ページ・期ページ（CHAT-0918-TP-11〜TP-13）: 入口と同じ写真カード（`photo_card_html()`・`.mj-title-holder*`）を並べる。帯の字の大きさは入口と同じく、並びの中で最も長い帯の字数で決める
  - 大会ページ: 各期の優勝者を新しい期から。帯に「第X期」、押すと期ページ。1位が2名の期（王位戦 第26期）は2枚。表と決勝メンバーの表示は無い
  - 大会ページ・期ページの見出しは画面に出さず（h1 は `visually-hidden`）、パンくず（1.125rem）を見出し代わりにする。大会ページの区分・状態・期の範囲の行も出さない（CHAT-0918-TP-14）
  - 期ページ: パンくず（最後の項目に対局日を「第1期（2021年3月30日）」の形で添える。空なら括弧ごと出さない。複数日の決勝は最終日、CHAT-0918-TP-17）→ 決勝に出た全員の写真 → 対局動画 → 放送。前後の期へのリンクは無い（TP-15 で廃止）。帯に順位（同順位はそのまま、第26期王位戦は2名とも「優勝」）、押すと X（新しいタブ）。X ID の無い選手はリンクにしない。決勝が5名の期（`.is-many`）はパソコン幅で1行に並ぶよう最大5列
  - 期ページの「放送」の節の後に、同じ大会・同じ期の /live の期ページへのリンク「放送対局」を置く（/live にその期があるときだけ。判断 LP-12、2026-09-19。/live 側からは「決勝結果（タイトル戦）」で戻る）。/live のページの有無は `data/live_pages.json`（/live が前回生成した一覧）で見る。詳細は docs/notes/live-page-design.md の 2-5「判断 LP-12」。前後の期の送りは /live にも付けない（TP-15 にそろえる）
  - 期ページに無いもの: 「この選手の他のタイトル・決勝進出」、大会の歴代優勝者、X・note のテキストリンク、「決勝メンバー」の語、「連盟プロ以外」の所属団体（データの整備後に出す、#397）
- 固定バーと検索（#364）: 入口・大会ページ・期ページのすべてに、タイトル戦のプルダウン（選ぶと大会ページへ移動）と検索欄のバーを置く。navbar とバーは最強戦の年度ページと同じく固定し、
  高さは `assets/title.js` が `--mj-title-nav-h`・`--mj-title-filter-h` に入れる。検索は最強戦トップ（`build_top_data`・saikyo.js）の形を写したもので、
  歴代の決勝メンバー全体を選手名・期の表記・大会名・年で探し、選手の写真カード→出場した期の一覧で出す。検索している間はページの本来の内容（`.mj-title-content`）を隠す。件数・0件の案内は出さない（TP-11）。
  データは `build_search_data()` が `title/search.json` に書き出し、検索欄を使ったときに読む（約420ページに埋め込むと重いため）。JS・CSS は最強戦と共通化していない
  - **年は「タイトル」タブの日付列から取る**（書式は下の「日付列の書式」）。2026-09-19 に平野さんが公開HPの年度を貼り、362期中360期が年を持つ（持たないのはリーチ麻雀世界選手権 第1・2回、#385）
- 期ページの対局動画（#222、CHAT-0918-TP-08〜TP-10）: 写真の直後の節「対局動画」に、「放送対局」タブ（/live と同じ `lib/sheets.fetch_records()` で読む）の
  決勝段階（決勝・決定戦・十段位決定戦）の回戦の行（表示=Y）を、卓 → 回戦（最終戦は最後）→ 枝番の順に載せる。期は（タイトル戦, 期）＝（大会名, `第N期`/`第N回`）で突き合わせ、西暦の期は対象外。
  「放送対局」の行を N にするとその期の節は消える（2026-09-19 に紅龍戦が N になり第1〜3期の節が消えた）。
  回戦名（`Game.label`）はサムネイルの左上の角に四角いタブ（`.mj-title-video-tag`）で重ね、下には文字を出さない（TP-14〜TP-15）。「放送」の節の動画は従来どおり下に文字
- **帯と回戦ラベルの色は `style.css` の `.mj-title` の変数2つ（`--mj-title-band-bg`・`--mj-title-band-fg`）だけで決める。** 今は黒の不透明度75%・白字（CHAT-0918-TP-16）。
  写真カードの帯（入口・大会ページ・期ページ）と回戦ラベルが同じ変数を読むため、1か所の変更で両方が変わる。
  配色を見比べるときは、実データの見本を並べた比較ページを生成スクリプトで一時的に書き出し、ラジオボタンと `:has(#…:checked)` で変数を差し替えた（JS なし・再読み込みなし。#364 の TN-01、TP-14〜TP-15。TP-16 で削除）。
  透過の案は明るい写真と暗い写真の両方で見る（帯の下の写真が透けるため）
- **入口の大会名の大きさは、下限も決める。** 「1行に収まる範囲で大きく」だけにしたら、幅360px（カード160px）で11.2pxになった（CHAT-0918-TH-04）。
  今は「帯（写真）の幅 ÷ 最も長い大会名の字数」（字数は生成時に CSS 変数 `--mj-title-taikai-em` で渡す）を14px〜1.25remに収め、下限で収まらない長い大会名だけ2行になる（TH-05）
- **龍龍（ron2.jp）の画像は、URL 末尾の `-150x150` を外すと元画像（320×240 程度）が取れる。** 生成時に取れるか確かめて置き換える。写真カード（入口・大会ページ・期ページ）で使う（CHAT-0918-TH-03・TH-04、大会ページ・期ページは TP-11）

## データ源

新しいスプレッドシート `<ライブ用スプレッドシートの ID>`（/live 用と同じ。値は `scripts/generate_title_pages.py` の `SPREADSHEET_ID`）の5タブ。

| タブ | 用途 |
|---|---|
| タイトル | 1行1名の決勝結果。表示=Y の行だけを使う。行の順は「この選手の他のタイトル」の並びに使う |
| タイトル戦 | 大会マスタ（大会名 / slug / 表示順 / 区分 / 状態） |
| 決勝動画 | 期ページの「放送」 |
| 連盟プロ以外 | **ryoei.pro 横断で使うタブ（旧「プロ以外」、先頭のタブ）。** 「プロ」にいない選手の所属団体・X ID・X画像URL。列は見出しの名前で読む（下記） |
| 別名 | **ryoei.pro 横断で使うタブ。** 旧名・誤記 → 現在の登録名 |

- 「連盟プロ以外」の必要な見出しは 名前 / 所属団体 / 所属補足 / 名前かな / X ID / X画像URL（並びは問わず、ほかの列があってもよい。CHAT-0916-TT-12。「所属補足」は旧「備考」、2026-09-18 改名、#384）。
  名前以外は空欄を許す。X ID があれば X のリンク（期ページ。入口の写真から X へのリンクは #358 で廃止）、X画像URL があれば「プロ」と同じ処理（既定アイコンの読み替え・`_400x400`）で写真の第1候補。名前かなは読むだけで使っていない
- gviz は存在しないタブ名でも先頭のタブを返し、「連盟プロ以外」はその先頭のタブ（gid=0）。旧名「プロ以外」で読んでも同じ内容が返るため、タブ名の誤りは見出しの照合でしか気付けない
- 「プロ」シートは `generate_jpml_pros.py` の定数（旧スプレッドシート）を使う。旧「タイトル」シートは新旧の一致検査にだけ使う
- 名前は「別名」を適用した現在の登録名で表示・照合する（連鎖は辿り、循環は生成を止める）。変換しないのは新旧の一致検査と、名前が「-」の行
- 名前が「-」の行は「—」・アバター・リンクなしで出す（失格で最終順位が無い場合と、記録が不明な場合の両方がある）

## 日付列の書式（#385、CHAT-0918-TP-12・TP-13）

「タイトル」タブの日付列（H列）は決勝日。その期の全行に同じ値を入れる。「XX」（小文字 `xx` も同じ）は仮（不明）の部分。

| 書式 | 意味 | 期ページの対局日 |
|---|---|---|
| `YYYY-MM-DD` | 確定した日付 | YYYY年M月D日 |
| `YYYY-MM-XX` | 年月まで（日が不明。予定の行など） | YYYY年 |
| `YYYY-XX-XX` | 年だけ。公式HPの「年度」を暦年とみなした仮の値（#385 の (B)）。後で実際の対局日に直す（#408） | YYYY年 |
| 空 | 不明 | 出さない |

- 「XX」を含む値は年度とも月とも書かない（予定の月は前後することがあるため、平野さん）。読めない値は出さずに警告する
- 入口の並び（決勝日の降順）では「XX」を0とみなす。検索の年（`period_year()`）は3つの書式のどれからも年を拾う
- 2026-09-19 時点（全3,271行）: `YYYY-MM-DD` 698 / `YYYY-MM-XX` 40 / `YYYY-XX-XX` 937 / 空 1,596 / それ以外 0。表示=Y の行に `YYYY-MM-XX` は無い

## 生成を止める条件と警告

- 止める: 5タブの見出しの不一致（gviz は存在しないタブ名でも先頭のタブを返すため）、置換文字（U+FFFD）・制御文字、slug の重複・不正・空欄（記録の無い大会の空欄だけは警告）、
  表示=Y の行の大会名が大会マスタに無い・期が空欄か数字でない・大会名/期/期の表記とタイトルの食い違い、
  「決勝動画」のタイトルが無い・動画IDが取れない、別名の循環、「連盟プロ以外」の必要な見出しの欠け・重複と名前が空欄の行、決勝メンバー行数の合計と表示する大会の表示=Y の行数の不一致
  （行の検査は非表示の大会の行にも行う。「決勝動画」の非表示の大会の期の行は読み飛ばす）
- 警告（生成は続ける）: 新旧の一致検査の不一致（全行で照合）、区分・状態の空欄・想定外の値、入口のタイトルホルダーの日付から年が取れない、期ページの対局日が読めない、
  「プロ」にも「連盟プロ以外」にもいない名前（20名以下になったら名前も出す。表示しない大会の行も含めて数える）、id の重複

## URL の解決（_redirects）

`html_handling: "none"` はディレクトリの index を解決しないため、`_redirects` に次の3行を置く。

- `/title  /title/  301`
- `/title/  /title/index.html  200`
- `/title/:slug/  /title/:slug/index.html  200`（プレースホルダを含む行は動的ルールになり、それ以降の行も動的扱いになるため、ファイルの末尾に置く）

`/title/<slug>`（末尾スラッシュなし）は 404。`/title/:slug  /title/:slug/  301` を足すと `/title/index.html` にも一致して壊れるため置かない。
確認は wrangler 同梱の asset-worker（miniflare）の `parseRedirects`・ルール照合のコードを抜き出して行った（CHAT-0916-TT-10。
セッション環境では `wrangler dev` が動かない）。本番の応答は第1段のマージ後に確認済み（CHAT-0916-TT-16: `/title` → 301、`/title/`・大会ページ・期ページ → 200、`/title/<slug>` → 404）。

## シートを直すときの注意

- **CSV を取り込む前に、列の並びが今のタブと合っているかを確かめる。** 「連盟プロ以外」を6列にした後に古い3列の CSV（`名前,-,`）を取り込み、
  所属団体の「-」が名前かな（B列）に入った（CHAT-0916-TT-13 で検知、TT-14 で列を移して復旧）。生成は見出しの名前で列を読むため、
  値が隣の列に入っても止まらず、表示から欠けるだけになる。
  **列構成を変えて取り込み用ファイルを作り直したときは、古いファイルを消すか、ファイル名に日付か Chat-Ref を入れる**
  （TT-13 で取り込まれたのは列が変わる前の TT-11 の CSV だった）
- **タブ名を変えるときは、読み込み側（`generate_title_pages.py` のタブ名の定数）を先に直す。** gviz は存在しないタブ名でも先頭のタブを黙って返すため、
  見出しの照合が無ければ誤ったタブを読んだまま生成が通る（「プロ以外」→「連盟プロ以外」の改名、CHAT-0916-TT-12）
- **「タイトル戦」タブは大会の追加・改名・表示順・区分・状態の正本。** ここを変えると「タイトル」タブとの整合で生成が止まることがある。
  「タイトル戦」側だけを 小島武夫杯帝王戦 → 帝王戦 に改名したとき、「タイトル」タブが旧名のままで表示=Y の20行が止まった
  （CHAT-0916-TT-14。TT-15 で「タイトル戦」を「小島武夫杯帝王戦」に戻して解消）

- **X の画像 URL が古くなると、`_400x400` が取れず `_80x80` のまま表示される。** 選手がプロフィール画像を変えると、古い画像は CDN で 200 と 404 が混ざる状態になり、
  生成時の確認で `_400x400` を置き換えない（閲覧者のブラウザでも同じ割合で 404 になるため、リトライで採らない）。直すのは「プロ」シートの J列
  （あわせて「タイトル」タブの G列）。現在の URL は `scripts/collect_saikyo_images.py` の `resolve()` で X ハンドルから引ける（CHAT-0918-TH-03、安東郁敬）

## 取り込み時の文字化け（CHAT-0916-TT-07〜TT-08）

- 取り込み用 CSV（UTF-8）のうち「髙」（U+9AD9）だけが置換文字2つに化けた。この文字は CSV の中で唯一 JIS X 0208（Shift_JIS / EUC-JP）に無い文字で、
  取り込みまでのどこか（ダウンロード後に開いた・保存したアプリ、アップロード時の文字コードの判定など）で JIS X 0208 の範囲に変換されたとみられる。どの段階かはセッションからは確かめられない
- 防ぐ手順: CSV はダウンロードしたファイルを他のアプリで開いて保存せず、そのまま「インポート」する。取り込み後は生成スクリプトを実行する（置換文字・制御文字があれば止まる）
- 「タイトル」タブは平野さんが直していく正本のため、取り込み用 CSV との差分は記録するだけで生成は止めない（CHAT-0916-TT-10 の判断 E）
