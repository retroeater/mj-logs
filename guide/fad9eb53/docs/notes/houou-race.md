# 鳳凰戦 リーグ別成績推移（houou_race.html、#507）

期・リーグを選び、▶で全員ゼロから節ごとに累計ポイントを数え上げ、追い越しで並びが入れ替わる順位表だけのページ。
スマホの幅（400px まで）に収める。**まだ公開していない**: noindex で、navbar・`sitemap-pages.xml`・`llms.txt` に載せず、既存のページからリンクしない
（公開は #508）。`houou_race/` の JSON はページが読むので配信の対象（`assets-check.yml` の allowed）。

## ファイル

| ファイル | 役割 |
|---|---|
| `scripts/generate_houou_race.py` | 「鳳凰」「プロ」を読み、ページと期ごとのJSONを書き出す。累計・帯の人数・降級の枠の行数・順位が付く最後の節はここで決める |
| `houou_race.html` | 生成。選べる組み合わせ（期・前後・リーグ・組）と既定の表示（43前 B1）を script の data 属性に焼き込む |
| `houou_race/<期>-<1|2>.json` | 生成。1は前期、2は後期。期を選んだときに読む（表ごとに分けると445ファイルになるため期ごと） |
| `houou_race.js` | 選ぶ部品・数え上げ・並べ替え・帯。計算はしない |
| `style.css`「鳳凰戦 リーグ別成績推移」 | 見た目。行の高さ `--mj-race-row` は JS も読む |
| `scripts/tests/test_houou_race.py` | 累計・帯・降級の枠・組の分け方・「表示」のテスト |

## JSON の項目

1ファイルは1期（前期か後期）で、表（リーグ、組があれば組）の配列。

| 項目 | 中身 | 出どころ |
|---|---|---|
| `league` | リーグ（A1〜E3） | 「鳳凰」D列「リーグ」 |
| `group` | 組の番号（0は組なし、1・2…） | 「鳳凰」X列「備考」の ①・② |
| `rounds` | 表の節の数（選手が打った節の数の最大） | 「鳳凰」I〜U列「第1節」〜「第13節」 |
| `players[].name` | 登録名 | 「鳳凰」A列「名前」 |
| `players[].short` | 名前チップの文字（名前の先頭2文字） | 同上 |
| `players[].img` | X の画像（`_200x200`）。既定アイコン・引けない選手は空 | 「プロ」J列「X画像」（Y列「表示」が Y の行） |
| `players[].x` | X の ID。アイコンのリンク先に使う。無ければ空 | 「プロ」I列「X ID」（同上） |
| `players[].cum` | 節0〜`rounds` の累計ポイント | 「鳳凰」I〜U列 |
| `players[].end` | 順位が付く最後の節（確定した表では打った最後の節、進行中の表では `rounds`） | 「鳳凰」I〜U列・G列 |
| `up` | 上側の帯 `{count, label}`。無ければ null | 「鳳凰」G列「結果」の「昇級」の人数。A1 は上位3名・「決定戦進出」 |
| `down` | 降級の帯 `{count, rows, label}`。無ければ null | `count` は G列「降級」の人数、`rows` は帯より下の行数（`count` ＋ 途中で終わった選手の人数） |

## データの読み方

- 「鳳凰」は `fetch_records()` で見出しの名前（名前・期・前後・リーグ・結果・表示・第1節〜第13節）で読む。第14節の列が増えたら `ROUND_COUNT` を変える
- V列「表示」が N の行は入れない（houou_results は `V = "Y"` の行だけ、houou_leagues は V列を見ない。どちらも変えていない）
- X列「備考」は Z列にも同じ見出しがあるため、`SELECT A,X` で読み、名前の列で行の対応を確かめる。値は「①組・②組」か「①・②」（期で書き方が違う）。
  組でも空欄でもない値、同じリーグで組の値がある行と無い行が混ざるときは生成を止める
- **第n節の列は、その選手が対局した順に詰めて入っている**（リーグ全体の節の番号ではない）。そのまま節の数にする（平野さん、2026-10-06）。
  空欄の節を挟む行（24後 A1 など）は前の累計のまま進める
- 対象は節の値が1つでもあるリーグ（23前〜43前、鳳凰位は除く）。A1・A2 はシート上「後」にだけある（ページでは「通期」）
- 「プロ」は `SELECT A,I,J WHERE Y = "Y"`（最強戦と同じ行）を名前で引く。X ID がシートの数式エラー（`#` で始まる）なら空にする

## 帯・降級の枠・順位

- G列に値があれば最終成績が確定した表とみなす
- 帯の人数は、最後まで打った選手の G列「昇級」「降級」の数。0人なら帯を出さない。A1 の上側だけは G列を使わず上位3名（「決定戦進出」）
- **降級の枠**: 降級は当初から G列の人数で、途中で休場した選手がその枠のいちばん下を占める、という建付け（平野さん、2026-10-06）。
  帯より下の行数は「降級の人数＋途中で終わった選手（1節も無い選手を含む）の人数」で、再生の間は動かない。降級が0人の表は帯を出さず、外れた選手は表のいちばん下に並ぶ。
  枠の行数が、最後まで打った選手の人数以上になる表があれば生成を止める
- 順位が付くのは、今の節をまだ打っている選手。第n節まで打った選手は第n節の終わりまで順位に入り、第n+1節の開始で枠のいちばん下に移り、順位は「–」、「第n節まで」を出す。1節も無い選手は最初からいちばん下で「出場なし」
- 並びは累計の降順。同点はシートの行の順（順位の順）。生成のときに、最後の累計の順で帯の内側に入る選手と G列が食い違う表と、途中で終わった選手の一覧を出す

## 見た目と動き

- 見出し（h1）は選ぶ部品と同じ幅・角丸のカード。字の大きさは3段（大: 見出し・期の数字・選ぶ部品／中: 選手名・ポイント・帯／小: 「第」「期」・節のラベル・順位・「第n節まで」）と名前チップ
- 並びは、期（ステッパー）・前期/後期（A は「通期」で押せない）・A〜E・番号・組（あるときだけ）。選べない組み合わせは押せない。期を送って今の組み合わせが無ければ、近いリーグ（同じなら同じ前後・組）に移す
- 再生前は帯も背景の色も出さない。▶で行の間が開き、昇級（決定戦進出）の帯は左から、降級の帯は右からすべりこみ、入り終わる（650ms）まで数え始めを待つ
- 1節は3秒の等速で数え上げ、全員同じ時刻に節の終わりの値に着く。節の間は0.7秒止まる。マイナスは赤字にせず「▲」だけ
- 帯より上・下の選手は、順位のマスも行も同じ色。再生中は表を押すと止まる（アイコンのリンクを押したときも）。節のラベルを押すとその節の終わりへ（帯を出した状態）
- もう一度見る（繰り返しの矢印）は、動きなしで最初の並びに戻してから帯が入り直す。動きを減らす設定では、▶で最終の状態だけを出す
- 選手のアイコンは、X の ID があれば `https://x.com/<ID>` を新しいタブで開く（`target="_blank" rel="noopener"`、title/・saikyo/ と同じ）。リンク先は `houou_race.js` の `playerUrl()` 1か所（将来、選手ページに差し替える）
