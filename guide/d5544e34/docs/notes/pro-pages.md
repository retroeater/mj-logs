# 連盟プロの新ページ `pro/`（トップ・選手ごとの個別ページ）

`jpml_pros.html` の後継（#219。未公開で、公開は #641）。決定は docs/decisions/pros.md の 2026-10-30・31。
選手ごとの URL・title・description を持ち、中身を HTML に焼き込む（players/ のように JS で描かない。#219 の N2・N3）。
見た目と部品は houou/ のもの（docs/notes/houou-top.md「共通」「選手を探す部品」、値は docs/notes/design.md）。
最小の画面幅 360px で折り返さない・はみ出さない（docs/notes/design.md「最小の画面幅」）。

## 構成

| URL | 中身 |
|---|---|
| `pro/` | h1「連盟プロ」・質問欄（AIコンシェルジュ。トップにだけ置く）・選手を探す部品（候補を押すと個別ページ）・今の絞り込みの1行（「五十音: あ」。押すと下からシートが出る）・在籍者の表 |
| `pro/<slug>/` | パンくず・名前の面・成績・獲得タイトル・放送対局（選手）・放送対局（実況・解説）。該当の無い面は出さない |

- slug（2026-10-30・31 の決定）: `<名>.<姓>.<入会期>`（名・姓は名簿の「【2】値貼付」の英字、小文字）。英字名の無い選手（芸名1語）だけ `<姓>.<入会期>`。語の間の空白・「-」は「-」1つ（例 `jun-young.lee.40`）。英字・数字・「-」以外が残る・英字姓か入会期が無い・重複するときは生成を止める（`slug_problems()`、全件に当てる）
- `_redirects`: `/pro` → `/pro/`（301）・`/pro/` と `/pro/:slug/` → `index.html`（200）
- OGP は全ページ「連盟プロ」の1枚（`img/ogp/pros/index-white.png`）。選手別の画像は 2026-10-31 にやめた（再開するときは git の履歴から戻す。PRO-02〜04 で作った描き方は 55a36fe9a までの履歴にある）

## トップ

- 表の列は 名前（40px の画像つき、左揃え）・所属・入会期・鳳凰・桜花（ほかは見出しも値も中央揃え。リーグはチップの中で中央）。行全体が個別ページへのリンク。見出しで並べ替え
- 絞り込みはシート（houou/race/ と同じ形）: 切り口のタブ「五十音・所属・入会期・リーグ」と値（各切り口の最後に「すべて」）。値を押すとシートを閉じて表を絞る
- 状態は URL のクエリ: `?kana=か`・`?place=東京`・`?joined=30`・`?league=C2`・`?all=1`（`&by=<切り口>`）。既定（あ行）はクエリなし。個別ページのチップから来る `?birthday=06-01`・`?ouka=C1` はシートのタブに無く、今の絞り込みの1行（「誕生日: 6月1日」）と「解除」だけ。無い値は既定に戻す

## 個別ページ

1. パンくず「連盟プロ / <名前>」
2. 名前の面: X の画像（72px の丸。無ければ頭の1字）・名前（28px の h1）・読みとローマ字・SNS のアイコン（X・note・YouTube。押せる大きさ 44px）・チップ（所属・入会期・誕生日・鳳凰戦のいまのリーグ・女流桜花のいまのリーグ）。チップを押すとトップで同じ値の選手に絞った一覧へ（`face_chips()`）。いま出場していない大会のチップは出さない
3. 成績: 鳳凰戦・女流桜花はいま出場しているときだけ、いまのリーグのチップつきの行。WRCリーグ・WRC-Rリーグ・麻雀最強戦は出場したことがあれば大会名だけの行。どの行も「最高」「出場」は出さない。押すとその大会の個人成績（`?name=`）へ（`result_rows()`）
4. 獲得タイトル: `title/search.json` の決勝の行のうち優勝の期を、期の名前（「第42期鳳凰戦」。title/ の期のページの名前を正式名称とした）で新しい順にすべて。押すとその期のページへ。最後に「すべての決勝進出」（`/title/?q=<名前>`）。決勝に出ていなければ面ごと出さない（`title_wins()`）
5. 放送対局（選手）・放送対局（実況・解説）: live/ のトップのカード（新しい順・サムネイルは live/ のカードと同じ画像）を、`generate_live_pages.load()` の対局者／実況・解説の現在名で分けて、それぞれ3件。「すべて（N件）」（`/live/?q=`）は live/ の検索が役で絞れないので1つだけ（選手の面、無ければ実況・解説の面）。N は live/ の検索と同じ部分一致（`live_cards()`）

- いまのリーグは各大会の `ask-players.json` の値（個人成績の名前の面のチップと同じ `current_league()` の値。進行中の期だけに出ている選手も入る）
- 「いま」の面・関連する選手・リンクのコピー・質問欄は個別ページに置かない（2026-10-31 の決定）
- title「<名前> | 連盟プロ | ryoei.pro」、description は名前・所属・入会期・いまのリーグから作る。構造化データは `Person`（name・alternateName〈読み〉・affiliation・sameAs・url）と `BreadcrumbList`。canonical は公開の段で付ける（#641 の K13）

## データと生成

- `scripts/generate_pro_pages.py`。在籍者（「プロ」の「表示」が Y）・読み・英字・所属・入会期・誕生日はシートから（`lib/sns.fetch_pros()`・`lib/meibo.py`）。大会ごとの値は各ページの生成物から読む（houou/・ouka/・jwrc/・wrcr/ の `ask-players.json`、`saikyo/ask-players.json`、`title/search.json`、`live/index.html`）。放送対局の役は `generate_live_pages.load()`（シートを読む）。そのため `regenerate.py` は `pro_pages` を最後に作る（`RUN_LAST`）
- 出力は `pro/`（`index.html`・`search.json`・`<slug>/index.html`）。在籍者でなくなった選手のディレクトリは消す
- 検査は `scripts/tests/test_pro_pages.py`（slug の規則・チップのリンク先・成績の行・獲得タイトルの並び・放送対局の役の分け方と件数・カードの読み取り）
- コンテナには鍵が無いので、生成・検査は `regenerate-page.yml` を作業ブランチで手動実行する（target_page `pro_pages`）
