## 割り当ての規則（`scripts/lib/abema_book.py`、CHAT-1012-ABM-10 の案）

1. 題名の先頭の「麻雀最強戦<年度>」「最強戦<年度>」を外し、末尾から卓を読む。`A卓`〜`D卓` → 英字の卓、`決勝卓`・`決勝戦`・`決勝`・`Final`・`final` → 決勝、`<n>回戦` とそれ以外（抽選会・インタビュー）→ 卓でない回
2. 対局名を正規化する（題名の対局名の部分とシートの対局名の両方）: NFKC → 先頭の大会名と年度を外す → スポンサー名（アース製薬杯・サイバーエージェント杯）を外す → 空白・「・」・「!！」・「&＆」・かぎかっこ・丸かっこ・「-」を外す → 英字を小文字に → 「ファイナルトーナメント」を「ファイナル」に。決勝のときだけ末尾の「1ststage」「2ndstage」を外す
3. 同じ年度のシートの対局を類似度（`difflib.SequenceMatcher`）の高い順に見て、0.6 以上で卓が当てはまる最初の対局に当てる（同じ類似度は 年度・対局日・対局名 の降順）
4. 英字の卓はその対局の英字が一致する最初の卓、決勝はその対局の英字の無い最後の卓
5. 1つの卓に2つ以上の回が当たったら、その卓には当てず、どの回も「なし」（理由つき）にする
6. 題名と対局名だけでは確かめられない対局（`CHECK_PLAYERS`。今は 2016 の ABEMA「著名人代表決定戦 麻雀代理戦争」）は、【1】の「対局者など」の名前と当たった卓の4人（どちらも「別名」で現在名に直す）が1人でも重なるときだけ当てる。重ならなければ別の対局として「なし」

## 司会・実況・解説の読み分け

「出演の一覧（ABEMA のまま）」を「／」で分けて読み直す（【1】の司会・実況・解説の列は使わない。書き方の違いで読み分けられていない回があるため）。

- 役の始まりは「役:名前」「役:」「<役>名前」「<役>」「役」（項目が役の名前だけ）の5通り。役の後ろの、役の無い項目は次の役までその役の人
- 【2】に載せる役: 司会・実況・司会・実況（両方に入れる）・解説。読み分けにだけ使う役: ゲスト解説・アシスタント・コーナー出演・アンバサダー・進行
- 最初の役より前の項目と卓の見出し（【A卓】・<A卓>）は対局者。「ほか」は捨てる。1つの役の複数の人は「／」でつなぐ
- 空白で区切られた2人（「桜井章一 森山茂和」など）は1項目のまま。直すときは【3】で
