## 2026-10-15（CHAT-1015-MTK-04）

- 「Mつく」タブを直した（平野さん）: 列の順番を入れ替え、「URL」を「動画ID」に（値は動画の ID）、「画像URL」「表示」「備考」を消し、「再生時間」を足した。値の無いセルは「-」にした
- 各話の見出しは、チームを作る人（ゲストのプロ）の名前と X の写真だけにする。チーム名は見出しに入れない
- タイトル「Mリーグチームを作ろう！」、自動の紹介文、検索欄の文言「選手名・チーム名で検索」は今のままでよい
- 「選んだ選手：…」の行はヒーロー（一覧・各話とも）から外す。各話の下のほうに、最強戦の卓のページの「出場者」のような形で選ばれた4人の写真を並べる。節の見出しは「指名選手」。写真の左上に「1巡目」〜「4巡目」を付ける（title/ の決勝ライブの「初日」のように）
- 巡目は、シートの名前1〜4の順を指名の順とみなす
- 写真は連盟以外の人にも出す（作る人と選ばれた4人）。登録の無い人は「連盟プロ以外」に追加する（シートへの追加は平野さん）。画像が未設定の人は、毎週の最強戦の登録漏れの検知に Mつくの節を足して知らせる
- 連盟以外の人も含めて、写真が読めなければ生成を止める（帰り道と同じ。代わりの画像に逃がさない）。止めるのは「プロ」「連盟プロ以外」に登録が無い人と写真が読めない人で、X の ID が無い人では止めない
- 再生時間はシートの「再生時間」列に手で入れる。YouTube の情報を週次で自動で取る仕組みは作らない（61本は平野さんが入れた）
