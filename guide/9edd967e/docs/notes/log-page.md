# 「ログ」のページ `log/`（検索の候補とタグ・駅名・現在地から探す）

「ログ」（麻雀プロが訪れた飲食店の X の投稿）のページ `log/` の仕様。作る issue は #639、公開は #640（旧ページ `resource_logs.html` は `log/` へ 301、生成はやめた）。
決定は docs/decisions/operations.md の 2026-10-28〜31（CHAT-1028-LGN-01〜CHAT-1031-LGN-10）の節。2026-10-29 に、Google の規約に合わせたデータ（Places は place_id だけ、駅・都道府県は国土数値情報、LGN-04〜08）の上に作り直した（LGN-09）。ここには決定を画面・データに落とした仕様を書く。
下の「仮置きの一覧」は、平野さんがプレビューで確かめるまでの仮の形。

## 目的

- 表・時系列の一覧をやめ、トップの検索を主な導線にする（2026-10-28 の決定）
- houou/ の個人成績（`houou/players/`）と同じ見た目（幅 400px・新サイトの基本の形・検索欄）にする
- 検索の候補（駅・投稿者・店名・投稿年・ジャンル・都道府県）とタグで絞る。現在地から探す（#378）を入れる
- 検索用のデータを分けて、表の全件をページに焼き込まない（`resource_logs.html` は 2.1MB・DOM 要素数の問題、#255）
- 谷岡育夫の再投稿（過去メシ）と、載せない店・投稿（催事・期間限定の出店・閉業・再掲）と、店名が空の投稿は出さない（下の「載せない投稿・店」）。石立岳大の投稿は 2026-11-10 に3層のシートから消した（下の「載せない投稿・店」）。閉業の店は毎月1日に自動で外す（2026-11-04 の決定、#664。ページに出るのは次の log/ の再生成の後。下の「データの持ち方」）
- Google から保存するのは place_id だけ。座標・営業状況・ジャンルは Google の値を使わない（2026-10-29 の決定、docs/notes/log-stations.md）

## 新しい投稿の写真と空欄

2026-11-12 から（2026-11-11 の決定、CHAT-1111-LGV-30）、毎朝の変換（`convert_x_posts.py` の all、`build_row()`）で、判定が飲食店の新しい投稿を次の2つで確かめ、当たれば【2】の「表示」を N にして平野さんに知らせる。既存の投稿は判定し直さない（既存の店のカードの写真は平野さんが目で確かめ、13件を【3】で直した。CHAT-1111-LGV-29）。

- 1枚目の写真（【2】の「画像」）を Claude Haiku（`judge_photo()`・`PHOTO_PROMPT`）が見て、主役が料理・飲み物でない（人物・同行者・動物・店の外観・看板・メニュー表・景色など）なら要確認の理由「写真が料理でない」。写真を取れない・Claude が答えない・答えが読めないときも安全側で「写真を判定できない」。写真は `pbs.twimg.com` の `name=small` で取り、base64 で渡す（保存しない）。費用は変換と同じ上限（1回の実行で $3）で数える
- 「店名」「駅」「メニュー」「Google マップの URL」「画像」のどれかが空なら、要確認の理由「空欄: <項目>」（`blank_fields()`）
- 知らせ: 常設 issue「ログ: 毎日確かめる投稿」（`run-daily.yml` の `xconvert-issue` が毎朝書き直す。0件で閉じる）。対象は【2】で上の理由のある行のうち、【3】の「表示」が空のもの。平野さんは【3】で、そのまま載せる → 「表示」Y／直して載せる → 空欄を埋める・「画像」に別の写真の URL を入れて「表示」Y／載せない → 「表示」N にする（入れると次の朝の一覧から消える）
- 判定の文の試し（2026-11-12、試しの mode。止める見本は平野さんが直した13件の1枚目、通す見本は載る店のカードの写真 1,695枚）: 止める見本 13件のうち13件を止め、通す見本は 3件（0.18%）を止めた。費用は1回 約 $0.20
- 今載っている投稿の空欄（2026-11-12、載る 2,358件）: 44件（駅 41・メニュー 3）。扱いは平野さんが決める（この時点では外していない）

## 載せない投稿・店

規則ごとの理由と決めた日。どれも生成のときに外し、シート（【3】）には書かない。毎朝の取り込みで投稿が増えても、規則に当たる投稿・店は載らない。外した数は生成のログ（「3層から N件のうち M件…」の行）に出る。

## 仮置きの一覧（平野さんがプレビューで確かめる）

- カテゴリの1行は10店
- 新着は最初の投稿の日付、投稿回数の多い店は投稿2件以上
- 説明文はページの下の今の位置（`.mj-lead`）のまま、文は「日本プロ麻雀連盟の麻雀プロが訪れた飲食店1,734店（2,430件）を、Xポストに基づいてまとめています。店名・メニュー・駅・投稿者で探せます。」
- 候補は種類ごとに3件、駅・投稿者・店名・投稿年・ジャンル・都道府県の順。行は種類の名前（「駅」など、小さく灰色、幅 4.5em）を先に置く。店数は今のタグと合わせた数
- タグは紺の丸いボタン（「×茗荷谷」）。現在地もタグにする。駅のタグを選ぶと現在地は外れる
- 店名の候補は店の名前だけから（同じ名前の店をまとめる。別名は候補に出さない、2026-11-04）。投稿年は「2025年」と出す
- 都道府県は駅の一覧の値（「東京都」の形）。一覧に無い駅は【県】の印から
- ジャンルは Claude が付ける（候補の一覧は後の指示で決める。列が無い間は候補に出ない）
- Google マップのアイコンは地図のピン（14px、リンクの色）。出典は説明文の文末の「利用条件・出典」の中（2026-11-05。前はトップの右上の「(i)」で、探した画面には出なかった）
- 結果は20店ずつ。投稿の写真は 120×68、カテゴリのカードは 160×90
- 現在地は、駅の点のある店が無い間、押せないアイコン（`disabled`、名前は「現在地から探す（準備中）」）にする（今のデータでは押せる）
- 検索欄の語は、別名も店の値として扱う（その店のどの投稿にも当たる。別名に「ラーメン」などの普通の語がある店は、その語で店の投稿がすべて出る）
- 0件の文は「見つかりませんでした。店名・メニュー・駅・投稿者の名前で探してください。」（タグで絞っているときも同じ）
- 打った語も `?tag=` に入れる。URL パラメータは上の「URL パラメータ」
- 白地のナビで「リソース」に印
- 【3】で駅を直した行は、【3】の駅の点・駅の候補・都道府県を使う（【2】の「駅の候補」は使わない）
