# 鳳凰戦の新ページ `houou/`（トップ・個人成績・ランキング・リーグ推移・順位変動）

鳳凰戦のページ群を `houou/` の下にモバイルファーストで作り直す仕様。親 issue は #518。
決定の一覧は docs/decisions/houou.md（2026-10-08〜）。ここには決定を画面・データに落とした仕様を書く。
仮置きは無い（2026-10-14 に、見た目の値をまとめて決定にし、残りも1つずつ決めて「仮置きの一覧」の節を消した）。

## 目的

- 旧4ページ（`houou_ranking.html`・`houou_leagues.html`・`houou_race.html`・`houou_results.html`）を `houou/` にまとめ、スマホで使える形にする
- ランキングの集計を Python の生成に移す（#141。女流桜花・WRC は後で同じ部品を使う）
- 成績詳細を Google Charts から静的 JSON の自前の検索に置き換える（鳳凰戦の分だけ。女流桜花・WRC の成績詳細は据え置き、#111）
- リーグ推移をスマホ向けに作り直す（#520 を取り込んだ）
- 女流桜花（`ouka/`）へ横展開できる作りにする（出力は鳳凰戦だけ）

### 選手を探す部品（個人成績・リーグ推移）

- 索引 `search.json` の1件は [名前, 読み, ローマ字, 最後の期, 最後のリーグ, 支部, 入会期, X の画像（80px）]（在籍者だけ）。NFKC・空白なし・小文字・カタカナ→ひらがなで突き合わせ、ローマ字は「姓名」「名姓」の両方で引ける
