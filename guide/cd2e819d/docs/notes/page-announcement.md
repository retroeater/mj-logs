# 新しいページの告知（X の投稿・告知動画）

新しいページを公開した後、X で告知するときの型。「鳳凰戦 順位変動」（`houou_race.html`、#507・#508）の告知を型にする
（平野さん、2026-10-08:「今後の告知は、概ねこのテンプレートで行く（動画の構成を含めて）」。`docs/decisions/page-release.md`）。
公開そのものの手順は `docs/new-page-checklist.md`。

## 進め方

1. チャット側が、動画の構成の表（秒・画面・テロップ）と投稿文の案を出す
2. 平野さんが OK とするか、文言を直す。あわせて下の「毎回確かめること」を確かめる
3. Claude Code が初版を作り、mp4 を `SendUserFile` で送る。制作のスクリプトは作業ブランチに置き、マージしない（状態は判断待ち）
4. 平野さんが動画を見て、直すか確定かを決める。直すときは作業ブランチで作り直して送る
5. 確定したら、制作のスクリプトと文書（ページの資料の「告知動画」の節）を cloudflare へマージする。動画はリポジトリに入れない（平野さんの端末に置く）
6. 平野さんが X に投稿する

- 決定（2026-10-20、平野さん）: 告知（告知動画）の制作を始めてから投稿までの間に、告知で挙げるページ・機能（質問欄など）を変えるマージを入れるときは、平野さんの明示的な指示・判断を必須とする。指示文に平野さんの承認が書かれていない変更は、この間はマージしない（2026-10-19 の WRC-R の告知で、投稿の直前・直後に質問欄の Worker を変えたため）
  - 期間（決定、2026-10-20、平野さん）: 告知動画の初版を作る指示（例 CHAT-1019-WRR-07）に着手した時点から、投稿が完了した時点まで。投稿の後の直しは、この決まりの対象外。チャット側は、期間中に告知に挙げるページ・機能を変える指示の「マージ:」の行に「告知の期間中の変更を承認（<日付>、平野さん）」と書く（chat-side-operations.md から移した）
  - Code の側の守り方: 期間中に、告知で挙げる機能のファイル（`workers/ask/src/`・その大会の生成のスクリプトなど）を変えてマージする指示で、冒頭の「マージ:」の行に平野さんの承認（日付と「告知の期間中の変更を承認」の趣旨）が無ければ、マージせずに止まって報告する。期間中かどうかは、その大会の告知動画の指示のログ（着手）と、下の「実例」の投稿の日時で判断する

## 告知動画の型

- 形式: 縦長 1080×1920・30fps・15〜30秒・mp4（H.264・yuv420p、音声 AAC）・音楽つき・白地に黒字。音量は loudnorm で -16 LUFS 前後
- 曲: `scripts/promo_video/title/music.py` の曲調 b（軽快・120 BPM。タイトル戦と順位変動で同じ曲）。場面の境目（デモの始まり・締めの画面の始まり）を渡して合成する
- 構成（順位変動の秒とテロップを例として添える）:

| 場面 | 画面 | 順位変動の秒 | 順位変動のテロップ |
|---|---|---|---|
| 1 タイトル | 白地にページの名前と、ひとことの説明 | 0〜2.5 | なし（画面の2行「鳳凰戦 順位変動」「リーグ戦の昇降級争いを再現」） |
| 2 選ぶ | 実画面で、選ぶ部品に順に枠を出す。表はページの既定の表示のまま | 2.5〜4.5 | 期とリーグを選んで |
| 3 操作 | 主な操作に押す印（丸）を出してから押す | 4.5〜5.4 | ▶ で再生（押す前から出す） |
| 4 本編 | ページの中心の動きを実際の速さで | 5.4〜13.5 | 各節の結果で、順位が入れ替わる |
| 5 早送り | 残りを早送り（3倍） | 13.5〜16.9 | 昇降級ボーダーの攻防 |
| 6 結果 | 結果の画面で止め、対応している範囲を出す | 16.9〜20.5 | 第23期〜第43期の全リーグ |
| 7 締め | 白地に `img/ogp.png` の「ryoei.pro」が1秒で現れ、その後は動かない。ほかの文字・URL は足さない | 20.5〜24 | なし |

- 最初のコマ: X のサムネイルになるので、タイトルはフェードインさせず最初のコマからはっきり出す（辞書の動画で採用、平野さん、2026-10-10）
- テロップ: 補足の説明が要る内容をテロップにする。1つ2秒以上。実画面の上（画面の上の端から 80〜210px）に置き、見せたい所を隠さない。画面の下の端から10%以上離す（X の再生の操作部が重なるため）
- テロップが名指すもの（線・選手・数字）は、そのテロップが出ている間に画面に映るコマがあることを、撮った後にコマを見て確かめる。止め方の決定で映らないときは、テロップを変えるか、途中で一度見せる（CHAT-1019-WRC-16）
- 実画面: 本番をスマホの幅（iPhone 13、390×664・3倍）で開き、高解像度のスクリーンショットの連番で撮る（実時間の録画は解像度が低い）。動画では 846×1440 の枠に入れる。写真は読み終わるのを待って撮り、白いままのコマを残さない
- 順位の表を止める画面は上位が映る位置にする。最後に表を送って下位・最下位の行だけを映すと「なお最下位はこの人です」という見え方になるため、そうしない（女流桜花 ouka/ の告知、2026-10-19）。表の途中の線（通過ライン・降級ラインなど）を見せたいときは、早送りの途中で一度その線まで送って見せ、上位が映る位置に戻してから止める（WRC リーグ jwrc/ の告知、2026-10-19）
- 止める位置・送る量を変えるときは、撮る前に、画面の上端に貼り付く要素（節の番号の段など）の高さと、画面に入る行数を測ってから決める（表を送って16位まで映そうとしたら、貼り付く段の下に1位が隠れた。撮ってから分かった、OUK-21）
- 時間で動くページは、撮る側で時計を1フレームずつ進める。やり方と落とし穴は `docs/notes/houou-race.md`「告知動画」の「撮り方」

## 毎回確かめること

動画ごとに平野さんに確かめる（型では決めない）。

- 人が映ること（選手の写真・名前・成績）。タイトル戦と順位変動は、どちらも「そのまま映してよい」だった
- 見本にするページ・表・選手（順位変動はページの既定の表示、タイトル戦は十段戦 第43期と選手 1人）
- 曲を変えるか

## 次に作る時に考える点

- 撮る側の時計の進め方を `scripts/promo_video/lib/` へまとめるか（`docs/notes/houou-race.md`「告知動画」）
