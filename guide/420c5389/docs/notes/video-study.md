# 女流勉強会（一覧 study/index.html・各話 study/）の実装記録

日本プロ麻雀連盟チャンネルの「女流勉強会」（英語名「Lady’s Mahjong Workshop」）の一覧と各話。帰り道（`docs/notes/video-wayhome.md`）・Mつく（`docs/notes/video-mtsuku.md`）と同じ仕様・デザインで作った（#575、2026-10-15）。
**未公開**（全ページ noindex。navbar・サイトマップ・`llms.txt` に載せず、どこからもリンクしない）。公開は #576。

## 構成

- データ: 帰り道・Mつくと同じ動画のブック（`lib/video_book.py`）のタブ「女流勉強会」（平野さんが持つ、2026-10-15・16 の決定）を見出しの名前で読む（`lib/study.py` の `fetch_tab_rows()`。列の並びに依存しない）。
  列は 動画ID・回・MC・講師・生徒。講師・生徒（と MC）は1つのセルに「、」区切りで名前を並べる（前後の空白は除く。「-」・空は0人）。タブが読めなければ止める。
  **タイトル・公開日・再生時間・メンバー限定はタブに持たず、動画IDで /live の層1 `data/live_channel_raw.jsonl` の最新の行から引く**
  （公開日は配信開始日時〈無ければ公開日時〉の JST、タイトルは YouTube の題名、メンバー限定は層1の「限定」）。タブに書いた動画IDが層1に無い・層1で配信予定か配信中の回があれば止める
- タブができるまで使っていた仮のファイル（`data/joryu_benkyokai_provisional.tsv`）と、それを層1の概要欄から書き出したスクリプトは、2026-10-16 にタブへ移って消した（CHAT-1016-JBK-05）
- 生徒: 平野さんがタブの「生徒」列に名前を入れた回だけ「生徒」の節が出る（2026-10-15・16 の決定）。一覧の文言・検索欄・紹介文には生徒を出さない。
  **生徒は止めない**（2026-10-16 の仮置き。講師・MC は今までどおり止める）: 「プロ」「連盟プロ以外」に登録があり X ID があって写真が読める人だけ写真入り、
  登録が無い・X ID が無い・写真が読めない人は名前だけ（代わりの絵）。「現役のプロとして同じ名前で活動している」かの判定を登録の有無で代えている（同姓同名の取り違えはあり得る）。
  生成と `--check` のログに、回ごとに「写真入り」「名前だけ（登録なし／X ID なし／写真が読めない）」の一覧を出す（`lib/study.py` の `student_report_lines()`）
- 2026-10-15 の層1では題名に「女流勉強会」を含む動画は40本（part34〜part73、すべて公開のライブのアーカイブ。メンバー限定は0本）。part1〜33 は YouTube に無いため扱わない（2026-10-16 平野さんが担当者に確認）
- 生成: 一覧 `scripts/generate_study.py`（ページ名 `study`、出力 `study/index.html`）、各話 `scripts/generate_study_episodes.py`（`study_episodes`、`study/`。データに無い動画IDのファイルを消す。`index.html` は除く）。
  読み方と止める範囲は `lib/study.py` の `prepare()`（動画IDの重複・講師が空・層1に無い・層1のタイトルが空・再生時間が読めない・サムネイル・登録が無い人・写真が読めない人で止める。X ID が無い人は止めない。Mつくと同じ）。`--check` あり
- 共有: サムネイル・再生時間・カード・固定の検索バー・戻る矢印は `lib/wayhome.py`、サムネイルの選び方・Xの写真の引き方・名前の辞書・JSON-LD の書き方は `lib/mtsuku.py` の関数を呼ぶ（帰り道・Mつくのコードは変えていない）。JS は `video_wayhome.js`（一覧）・`wayhome_episodes.js`（各話）
- URL: `/study/`（2026-10-16 平野さんの決定。仮置きの `/benkyokai/` から変えた。未公開だったので旧 URL の転送は作っていない）。
  内部の名前（スクリプト・モジュール・ページ名・CSS のクラス・テスト・この文書と決定の記録のファイル名）も 2026-10-16 に `benkyokai` から `study` にそろえた（平野さんの決定、CHAT-1016-JBK-08）
- 転送: `_redirects` に `/study  /study/  301`・`/study/  /study/index.html  200`。サイトマップは書き出さない（公開のときに足す。`docs/notes/redirects.md` の末尾スラッシュの行にも公開のときに `/study` を足す）
- 「使われていない登録」の検査（`check_unused_names.py`）は女流勉強会の講師・MC・生徒を利用先として数える
- `check-assets.yml` の最上位の許可リストに `study` を足した（2026-10-16）
- テストは `scripts/tests/test_study.py`

## 帰り道・Mつくとの違い

- 見出しは動画のサムネイル（ヒーローの背景）とタイトル（2026-10-15 平野さんの決定。人の名前と写真は見出しにしない）。見出しの文字は YouTube の題名から【無料放送】などの【】の札とシリーズ名「女流勉強会」を外した回の部分（`heading()`、例「part73」。同日の決定）。
  当てはまらない題名（シリーズ名で始まらない）は【】の札を外しただけのもの。一覧のヒーロー（最新話）・一覧のカードの題名の行も同じ
- 一覧のシリーズ名（h1）に英語名「Lady’s Mahjong Workshop」を小さく添える（`.mj-study-en`、`lang="en"`）。`<title>`・og:title・各話には入れない
- 一覧の `<title>`・og:title は「女流勉強会 | 番組 | ryoei.pro」（`list_page_title()`。メニューの改称に合わせた、2026-10-16 平野さんの決定）
- 講師・MC・生徒の名前は名前の辞書の「別名」を通して現在名にする（例: タブの「山口大和」→「大和」）。写真・検索の文字・紹介文も現在名。
  旧名と、タブの知らない列（「備考」など。列は見出しで選ぶので読まない）がページに出ないことは `test_study.py` の `OldNameTest`。生徒の名前はログに出さない: 環境変数 `CI` が立っているとき（Actions）は件数だけ（`student_summary()`）、手元では回ごとの一覧（タブに書いた名前のまま）と SNS ブックが写真をまだ取っていない生徒の警告も出す（`student_report()`、`HIDE_NAMES_ENV`。2026-10-16 平野さんの決定。テストは `StudentLogTest`）
- `<title>`・og:title・パンくず（`BreadcrumbList`）・前後のリンク・カードの画像の alt はシリーズ名つきの「女流勉強会 part73」（【】の札だけを外した題名、`display_title()`）。
  `<title>` はその後に講師を付ける（例「女流勉強会 part73 藤島健二郎・三浦智博・阿久津翔太 | ryoei.pro」）。日付の行は「公開日・再生時間」
- 各話の写真カードの節を 講師 → 生徒 → MC の順に並べる（空の節は出さない。札は付けず、節の見出しが役を表す）。生徒は名前を入れた回だけ（今は全回空）
- 「〇〇の他のエピソード」の節は出さない（前後のエピソードだけ。2026-10-15 平野さんの決定）
- メンバー限定の回: カードのサムネイルの左上に「メンバー限定」の札（`.mj-study-members-tag`）、ヒーローの日付の行の先頭に「メンバー限定」の札（「最新話」と同じ形）。一覧の検索で「メンバー限定」と打つと拾える
- 構造化データ（JSON-LD）: 一覧は `ItemList`、各話は `BreadcrumbList` だけ。プレーヤーを埋め込まないので `VideoObject` は一覧（#620）・各話（#629）とも置かない（2026-10-24 の決定、docs/decisions/mtsuku.md）。og:type（video.other）・og:video は残す
- 紹介文は自動: 「日本プロ麻雀連盟の「女流勉強会」。<講師>プロ・…が講師を務めた回です。」
- 一覧の検索は 公開日・タイトル・講師・MC・メンバー限定の札（生徒は名前を入れた回だけ）。検索欄は「選手名で検索」、読み上げのラベルと一覧の文は「講師の名前で…」。`?name=` は読まない（旧ページが無い）
- 一覧の og:image は最新話の YouTube サムネイル。一覧は canonical なし、各話はあり（Mつくと同じ）。総再生時間は常に出す（再生時間が空の回は生成が止まる）
- 再生時間は2時間前後（Mつくの「1時間以上は読み違い」の確かめは使わない）
