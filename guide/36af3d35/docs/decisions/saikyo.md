## 2026-10-10（CHAT-1010-XAP-05）

- SNS ブックの ID は `1CQyTzlPLXttBZr4-C_l5KX6PDbGXU69arXXP0I5VW2g`。コードに書いてよい（正本・/live 用と同じ扱い）
- 移す列は X・note・YouTube のすべて。選手は名前で見分ける（固定 ID は作らない）。生成を切り替えた後、旧列（「プロ」の X・note・YouTube の列、「連盟プロ以外」の X ID・X画像URL）は値を空にし、列は残す
- タブは4つ: 【1】元データ（シート・名前・名前かな。「プロ」「連盟プロ以外」から常に最新の一覧、シート > 名前かな > 名前の順）、【2】ID（【1】の3列に続けて平野さんが X・note・YouTube・備考を入力）、【3】画像取得（【2】の ID から取れる画像の URL を自動で取る）、【4】手動補正（【3】を上書きしたいときだけ平野さんが入力）
- 了承した提案: 【2】は名前で【1】と突き合わせて入力ごと行を並べ替え、新しい人は足し、一覧から消えた人は消さずに状態「一覧に無い」で末尾へ。SNS の列の「-」は確認済みのアカウントなし、空欄は未調査。【3】は前の値を残し、URL が取れない・ID が変わった行だけ取り直す（最初は API を使わず今の値から写す）。【3】に X数値ID と SNS ごとの取得日・状態を持つ。【4】は上書きしたい人の行だけ、見出しは【3】と同じ、空のセルは上書きしない、備考列を持つ。別の SNS は【2】に列を足すだけで済む作り
- 検知からの自動補正は、機械が【3】を書き直す形にする。【4】の値が取れないときは自動で直さず検知の issue に出す（2026-10-10〈CHAT-1010-XAP-04〉の「壊れた URL と一致するセルだけを置き換える（findReplace）」を置き換える）
