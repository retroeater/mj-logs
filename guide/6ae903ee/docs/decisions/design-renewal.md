# 新サイトのデザインの基本の形

新サイト（#296）の見た目の基本の形（面・色・選ぶ部品・文字の大きさ・ナビ）の決定。issue は #107。
値（色・寸法）は、houou/ に当てはめて `style.css` に入った時点で `docs/notes/design.md` の各表へ移す（それまでの見本の値は `houou/design-sample/` とその作業ログ）。

## 2026-10-12（CHAT-1012-DSN-01・CHAT-1012-DSN-02）

チャットでの1問1答（Q1〜Q11）の決定。DSN-01 は issue の重なり（#107）で止まり、DSN-02 で記録した。

進め方:

- 対象は新サイト #296 のデザインを固めること（現行サイトの全面作り直しではない）。最初の画面は houou/。基準は「最高品位」（WCAG AAA を全ページの条件にする意味ではない）
- 参考は公開されているスポーツ系のアプリ・サイト（Apple Sports・FotMob）。Mobbin は使わない（Free プランでは MCP が使えない）
- まず見本のページを作り、平野さんが iPhone で見て OK を出してから houou/ に当てはめる（未マージ）
- issue は新しく起こさず #107（新サイトの UI 方針）を使う。「状況: 保留」を外す（DSN-01 への回答 (a)）

基本の形:

- 「カードをやめて面にする」を新サイト全体の基本の形にする。1つの節を1枚の面にし、行は細い線で区切る。題名の枠と、行ごとの影をなくす。最強戦・title/ の Material 寄りの見た目は、いずれこちらに寄せる（grill Q1。#107 の本文の「カードUIパターン」はこれで決まったものとする）
- 強調色は紺 `#14459b` の1色（リンク・選んだ状態・主なボタン）。Bootstrap の青 `#0d6efd`（質問ボタンなど）はやめる（grill Q2）
- 選ぶ部品は「灰色の溝の中で、選んだ1つが白く浮く」形（iOS のセグメント）にそろえる。選んだ字は太字の紺。1行に入らないもの（ランキングの9部門など）は同じ形で横スクロール（grill Q3）
- 文字の大きさは4段: 大 28px 太字（題名・要約の数字）／本文 16px（名前・行の数字）／小 13px 灰色（説明・列名・注記）／極小 12px 太字（ピルの字）。強弱は「大きさ」と「灰色かどうか」だけで付ける（grill Q9）
- 面は角丸 12px・影なし。面の地は白、ページの地はごく薄い灰色（iPhone の「設定」の形）。行の区切りは 1px の薄い線（grill Q10-4）
- 題名は枠を外して左寄せ、28px 太字、下に余白（grill Q10-5）
- 写真の無い選手は、名前の頭の1字を灰色の丸に書いた形に統一する（灰色の人型・イラストはやめる）（grill Q10-3）
- ダークモード: 新サイトは最初から両方の色を決める（既決）。houou/ も今回の作り直しで暗い配色の値まで決める（grill Q10-6）
- 「手応え」は影の代わりに、押したときに行の地が薄い灰色に変わることと › で出す。「楽しさ」は配色ではなく再生の動きで出す（grill Q11。`houou.md` の 2026-10-09〈CHAT-1009-HOU-05〉の「カードは立体的で…」「ビビッドで楽しい配色にする」を置き換える）

共通ナビ:

- 白地にし、本文との境目は下の細い線。今いるページの項目を紺で示す。濃色の例外（帰り道・live/）だけ、ナビもそのページの濃色に合わせる（grill Q7）
- 項目名は日本語1行（日英2行をやめる）。英語は別 URL の英語ページ（`/en/`）で扱い、新しい issue は起こさず #226 にまとめる（grill Q8）
- #226 のローマ字は要件2のまま（平野さんがシートに書き、スクリプトでは変換しない）。API で訳す案の対象は見出し・説明文・注釈だけ（DSN-01 への回答 (a)）

houou/ の画面:

- トップは4項目を1枚の面に4行（題名・説明・右端の ›）で並べ、アイコンはやめる。質問欄を4項目の上に置くことは変えない（grill Q6） → 置き換え（行の数）: 2026-10-12（CHAT-1012-DSN-03）
- 質問欄は1行の入力欄。例文は「例：23期生の鳳凰位は？」程度に短くする。注意書き3行は1行にまとめ、ⓘ で3行の全文を開く（注意書きの文言は変えない）（grill Q10-2）
- 順位変動の選び方は、表の上に「第43期前期・B1 ▾」の1行だけを置き、押すと下からシートが出て期・前後期・リーグを選ぶ。節は表のすぐ上に1行で残す（grill Q4） → 置き換え（題名そのものを「第43期前期 B1 ▾」に）: 2026-10-14（CHAT-1014-DSN-10）
- 再生ボタン（順位変動・リーグ推移）はデータの上に重ねず、題の行の右端に小さな丸のボタンで置く（grill Q10-1）
- リーグは灰色の濃淡（リーグの印は灰色の地に字だけ。リーグ推移のグラフは A1 を濃い灰色、E を薄い灰色）。選手の線だけを紺にする。昇級・降級のピルは色を残す（grill Q5） → 置き換え（灰色の濃淡）: 2026-10-13（CHAT-1013-DSN-04） → 置き換え（リーグの段と印の色）: 2026-10-13（CHAT-1013-DSN-05）、リーグの色は今の houou/ の色（選手の線を紺、昇級・降級のピルの色は変わらない）
