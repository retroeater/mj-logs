# 鳳凰戦の新ページ `houou/`（トップ・個人成績・ランキング・リーグ推移・順位変動）

鳳凰戦のページ群を `houou/` の下にモバイルファーストで作り直す仕様。親 issue は #518。
決定の一覧は docs/decisions/houou.md（2026-10-08〜）。ここには決定を画面・データに落とした仕様を書く。
仮置きは無い（2026-10-14 に、見た目の値をまとめて決定にし、残りも1つずつ決めて「仮置きの一覧」の節を消した）。

## 目的

- 旧4ページ（`houou_ranking.html`・`houou_leagues.html`・`houou_race.html`・`houou_results.html`）を `houou/` にまとめ、スマホで使える形にする
- ランキングの集計を Python の生成に移す（#141。女流桜花・WRC は後で同じ部品を使う）
- 成績詳細を Google Charts から静的 JSON の自前の検索に置き換える（鳳凰戦の分だけ。女流桜花・WRC の成績詳細は据え置き、#111）
- リーグ推移をスマホ向けに作り直す（#520 を取り込んだ）
- 女流桜花（`ouka/`）へ横展開できる作りにする（出力は鳳凰戦だけ）

## 通期のリーグ（#541、2026-10-17）

「鳳凰」シートの A1・A2・鳳凰位は前期・後期に分かれない（通期）。**シートの「前後」は「-」で入れる**（44期以降の行も同じ）。
「後」・「前」が入ると生成は止まり、止める理由にシートの行（期・リーグ・名前）と直し方が出る（`lib/houou_tab.py` の `half_error()`）。

| 場所 | 通期の形 | 理由 |
|---|---|---|
| 読む所 | `lib/houou_tab.py` の `term_half(リーグ, 前後)`: 通期のリーグの「-」は `SPAN`（「通」）、ほかのリーグは「前」「後」。それ以外（通期のリーグの「後」「前」・ほかのリーグの「-」）は None（生成を止める） | リーグ名で通期を決めるのは、シートを読むこの1か所（と下の進行中の期）だけにする |
| 画面・質問欄 | 通期かはデータの通期の印で決める（成績 JSON・`data.json` の期の番号 0、順位変動の期のキー `<期>-0`）。`assets/league.js` の `termShort()`・`termLong()`・リーグのタブの吹き出し・順位変動の URL、`assets/league_race.js` の「通期」の表示、`workers/ask/src/query.mjs` の `termLabel()`・`league()` | データの形だけで決め、リーグ名の一覧を画面側に持たない（段3） |
| 進行中の期 | `houou_upcoming` は選手ごとにリーグだけを持つ（通期の印が無い）。`assets/league.js` の `upcomingTerm()` と `generate_houou_pages.py` の `upcoming_last()` だけがリーグ名で通期にする | 形を変えると生成物が変わるため（段3 は生成物を変えない） |
| 成績 JSON・質問欄の `data.json` | 行の期の番号は 0（前期 1・後期 2）。`lib/results.py` の `HALF_NUMBERS` | 1・2 と重ならず、JS で偽になる値。並び（`HALF_ORDER`）は後期と同じ位置で、行の順は前と同じ |
| 順位変動 | 期のキーは `<期>-0`（ファイル `houou/race/42-0.json`、選択肢の `data-index` の前後 `"0"`）、URL は `?term=42&league=A1` | 前期・後期のファイルと分ける。URL は期だけで通期を表す。古い `?term=42-2&league=A1` は読み替えない（2026-10-17。開くと近いリーグとして通期の A1 に移る） |
| 期の数え方 | 前期・後期は前期・後期のリーグの行で決め、通期のリーグはその期の前期・後期の両方に数える（`standings()`・`leagues_data()`・`leaguePositions()`）。通期の行の全体の順位・人数はその期の最後の単位（後期）の数 | 前と同じ結果（旧の「後期から前期へ写す」を、通期を両方に出す書き方にした） |
| 現在のリーグ・進行中の期 | 通期の行はその期の前期・後期の両方に当たる（`in_term()`・`inTerm()`、`upcoming_term()`、`lib/pro_stats.py` の `in_half()`）。Ampai のリンクは最新の期の前後の行を引く（Ampai のブックは通期のリーグも前・後の2行を持つ） | jpml_pros の「鳳凰<最新の期>」・Ampai のリンクを前と同じにする |
| 旧ページ | `generate_houou_race.legacy_half()`・`generate_houou_leagues.legacy_load()` が入口で「-」を「後」に戻す（houou/ と共有する関数には入れない） | 旧ページは #582 で片付けるので直さない。出力は前と同じ |
