# 鳳凰戦 順位変動（houou_race.html、#507）

期・リーグを選び、▶で全員ゼロから節ごとに累計ポイントを数え上げ、追い越しで並びが入れ替わる順位表だけのページ。
スマホの幅（400px まで）に収める。navbar「鳳凰戦」の「リーグ推移」と「成績詳細」の間の「順位変動」・`sitemap-pages.xml`・`llms.txt` に載る（公開は #508）。
ページの名前は「順位変動」（2026-10-07 に「リーグ別成績推移」から改めた。隣の「リーグ推移」と紛らわしいため）。URL・ファイル名・クラス名の race はそのまま。
説明文（meta description・og:description・ページ末尾の段落）の期の範囲（「第23期〜第43期」）は、書き出す期の最初と最後から生成スクリプトの `describe()` が入れる
`houou_race/` の JSON はページが読むので配信の対象（`assets-check.yml` の allowed）。

## ファイル

| ファイル | 役割 |
|---|---|
| `scripts/generate_houou_race.py` | 「鳳凰」と名前の辞書（「プロ」「連盟プロ以外」「別名」）を読み、ページと期ごとのJSONを書き出す。累計・帯の人数・順位が付く最後の節はここで決める |
| `houou_race.html` | 生成。選べる組み合わせ（期・前後・リーグ・組）と既定の表示（`pick_default()` がデータから選ぶ。下の「既定の表示」）を script の data 属性に焼き込む |
| `houou_race/<期>-<1|2>.json` | 生成。1は前期、2は後期。期を選んだときに読む（表ごとに分けると445ファイルになるため期ごと） |
| `houou_race.js` | 選ぶ部品・数え上げ・並べ替え・帯。計算はしない |
| `style.css`「鳳凰戦 順位変動」 | 見た目。行の高さ `--mj-race-row` は JS も読む |
| `scripts/tests/test_houou_race.py` | 累計・帯・降級の枠・組の分け方・「表示」・画像と X の引き方のテスト |

## JSON の項目

1ファイルは1期（前期か後期）で、表（リーグ、組があれば組）の配列。

| 項目 | 中身 | 出どころ |
|---|---|---|
| `league` | リーグ（A1〜E3） | 「鳳凰」D列「リーグ」 |
| `group` | 組の番号（0は組なし、1・2…） | 「鳳凰」X列「備考」の ①・② |
| `rounds` | 表の節の数（選手が打った節の数の最大） | 「鳳凰」I〜U列「第1節」〜「第13節」 |
| `players[].name` | 登録名 | 「鳳凰」A列「名前」 |
| `players[].short` | 名前チップの文字（名前の先頭2文字） | 同上 |
| `players[].img` | X の画像（`_200x200`）。既定アイコン・引けない選手は空 | 「プロ」J列（Y列が Y の行）か「連盟プロ以外」の「X画像URL」 |
| `players[].x` | X の ID。アイコンのリンク先に使う。無ければ空 | 「プロ」I列か「連盟プロ以外」の「X ID」 |
| `players[].result` | G列の値。順位から外れたときの置き場所（降級の枠か、帯のすぐ上か）に使う | 「鳳凰」G列「結果」 |
| `players[].cum` | 節0〜`rounds` の累計ポイント | 「鳳凰」I〜U列 |
| `players[].end` | 順位が付く最後の節（確定した表では打った最後の節、進行中の表では `rounds`） | 「鳳凰」I〜U列・G列 |
| `up` | 上側の帯 `{count, label}`。無ければ null | 「鳳凰」G列「結果」の「昇級」の人数。A1 は上位3名・「決定戦進出」 |
| `down` | 降級の帯 `{count, label}`。無ければ null | `count` は G列「降級」の人数（途中で終わった選手を含む）で、帯より下の行数 |

## データの読み方

- 「鳳凰」は `fetch_records()` で見出しの名前（名前・期・前後・リーグ・結果・表示・第1節〜第13節）で読む。第14節の列が増えたら `ROUND_COUNT` を変える
- V列「表示」が N の行は入れない（houou_results は `V = "Y"` の行だけ、houou_leagues は V列を見ない。どちらも変えていない）
- X列「備考」は Z列にも同じ見出しがあるため、`SELECT A,X` で読み、名前の列で行の対応を確かめる。値は「①組・②組」か「①・②」（期で書き方が違う）。
  組でも空欄でもない値、同じリーグで組の値がある行と無い行が混ざるときは生成を止める
- **第n節の列は、その選手が対局した順に詰めて入っている**（リーグ全体の節の番号ではない）。そのまま節の数にする（平野さん、2026-10-06）。
  空欄の節を挟む行（23後 C2 の山田圭、28後 D3 の丹羽卓哉。どちらも第2節）は前の累計のまま進める。
  シートで詰めると「第4節まで」になり、山田圭が昇級の帯の外に出るため、直さない（平野さん、2026-10-07）
- 対象は節の値が1つでもあるリーグ（23前〜43前、鳳凰位は除く）。A1・A2 はシート上「後」にだけある（ページでは「通期」）
- 画像と X の ID は saikyo/ と同じ引き方: 名前を「別名」で現在名に直し、「プロ」（`SELECT A,I,J WHERE Y = "Y"`）か「連盟プロ以外」（見出しの名前で読む）から引く。部品は `lib/names.py` の `NameBook` を借りる。表に出す名前は「鳳凰」の名前のまま。X ID がシートの数式エラー（`#` で始まる）なら空にする

## 既定の表示

- `pick_default()` が、表に出す対象（V列「表示」が N の行と、節の値が1つも無いリーグを除いた後）から選ぶ（平野さん、2026-10-07）:
  いちばん新しい期（期の数字が大きいほう、同じ期なら後期）→ その期のいちばん上のリーグ（`LEAGUES` の順）→ 組があれば番号のいちばん小さい組
- 選ばれた表が進行中（G列が空欄）なら生成を止める。進行中の表は「表示」を N にしておく運用で、止まったら V列を N にするか G列を入れる。
  既定に選ばれない表は進行中でも描く（`players[].end`）
- A1・A2 はシート上「後」にあるので、ある期の「後」の行を表示に切り替え節の値が入ると、既定はその期の A1（通期）に移る。A1 が確定していなければ止まる

## 帯・降級の枠・順位

- G列に値があれば最終成績が確定した表とみなす。確定した表では1節も無い選手を入れない（帯の人数にも数えない）
- 昇級の帯の人数は、最後まで打った選手の G列「昇級」の数。A1 の上側だけは G列を使わず上位3名（「決定戦進出」）
- **降級の枠**: 降級は当初から G列の人数で、途中で休場した選手がその枠のいちばん下を占める、という建付け（平野さん、2026-10-06）。
  帯より下の行数は G列「降級」の人数（途中で終わった選手を含む）で、再生の間は動かない。0人なら帯を出さない。
  枠の行数が表の人数以上になる表があれば生成を止める
- 順位が付くのは、今の節をまだ打っている選手。第n節まで打った選手は第n節の終わりまで順位に入り、第n+1節の開始で、
  G列が降級なら降級の枠のいちばん下、そうでなければ降級の帯のすぐ上（帯が無ければ表のいちばん下。24前 D2 の例）に移る。順位は「–」で色は付けない（枠の中なら降級の色）、「第n節まで」を出す。
  順位の数字は、順位が付いている選手だけに上から振る
- 並びは累計の降順。同点はシートの行の順（順位の順）。生成のときに、最後の累計の順で帯の内側に入る選手と G列が食い違う表と、途中で終わった選手の一覧を出す

## 見た目と動き

- 見出し（h1）は選ぶ部品と同じ幅・角丸のカード。字の大きさは3段（大: 見出し・期の数字・選ぶ部品／中: 選手名・ポイント・帯／小: 「第」「期」・節のラベル・順位・「第n節まで」）と名前チップ
- 並びは、期（ステッパー）・前期/後期（A は「通期」で押せない）・A〜E・番号・組（あるときだけ）。選べない組み合わせは押せない。期を送って今の組み合わせが無ければ、近いリーグ（同じなら同じ前後・組）に移す
- 再生前は帯も背景の色も出さない。▶で行の間が開き、昇級（決定戦進出）の帯は左から、降級の帯は右からすべりこみ、入り終わる（650ms）まで数え始めを待つ。
  帯より上・下の色は、全員 0.0 の間（帯が入り終わるまで）は付けず、ポイントが動き出してから付ける（平野さん、2026-10-06）
- 1節は3秒。全員が同じ速さで数え、速さは「その節でいちばん動いた選手（その節を打った選手の中で）が3秒かけて着く」速さ。小さく動いた選手は先に着いて止まり、いちばん動いた選手が節の終わりまで数え続ける（平野さん、2026-10-06。試作の「同時に着く」「同じ速さ A」「同じ速さ B」の見比べで A）。いちばん大きい動きは `houou_race.js` が JSON の `cum` から表ごとに求める（`nodeMax`）。節の間は0.7秒止まる。マイナスは赤字にせず「▲」だけ
- 帯より上・下の選手は、順位のマスも行も同じ色。再生中は表を押すと止まる（アイコンのリンクを押したときも）。節のラベルを押すとその節の終わりへ（帯と色を出した状態）
- もう一度見る（繰り返しの矢印）は、動きなしで最初の並び（帯も色も無い）に戻してから帯が入り直す。動きを減らす設定では、▶で最終の状態（帯と色あり）だけを出す
- 選手のアイコンは、X の ID があれば `https://x.com/<ID>` を新しいタブで開く（`target="_blank" rel="noopener"`、title/・saikyo/ と同じ）。リンク先は `houou_race.js` の `playerUrl()` 1か所（将来、選手ページに差し替える）
