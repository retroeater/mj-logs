### 2. 原因

**枠の組み分けが「同じ日・同じ題名」だけで、無料版の題名が放送後に変わると限定版の組から外れ、限定版の無い組の公開版として完全版になる。** CAL-12 grill Q3（同じ種類の版が2本）でも、版の判定の誤りでも、仮の予定からの切り替えでもない。

経路（`scripts/lib/live_calendar.py` の `build_desired()` → `scripts/lib/yotei.py` の `full_frames(split=True)`）:

```python
# yotei.full_frames()
groups[(frame_date(v), normalize(v["タイトル"]))].append(v)
...
members = [v for v in vs if v["限定"] == "Y"]
public = [v for v in vs if v["限定"] != "Y"]
...
if not members:
    frames += [(v, None) for v in public]
```

- 09-28〜10-01 朝: dFOIYiIeQy4 と lRfK1G89L-M は同じ題名（印を外して「第1期鳳匠戦ベスト16A・B卓」）で同じ組。lRfK1G89L-M が完全版、dFOIYiIeQy4 はその無料版で、予定は1件（09-28 07:54 作成）
- 10-01 の放送中に、連盟が B卓を別の枠（限定 hEcZKGw62pA・公開 YkDnyZIYa3c、「B卓」）に分け、A卓の公開版 dFOIYiIeQy4 を「第一期鳳匠戦ベスト16A」に改名した（限定版 lRfK1G89L-M は「A・B卓」のまま）
- 10-01 22:00 UTC の取り込みで層1に改名が入り、dFOIYiIeQy4 は組「第1期鳳匠戦ベスト16A」に1本だけ → `if not members:` で公開版が完全版になり、`key=video:dFOIYiIeQy4` の予定が作られた
- 件名は2件とも /live の【2】の卓 A から `match_title()` で「第1期鳳匠戦 ベスト16 A卓」になり、同じ件名に見える

`excluded`（【4】）・`by_video` の結び付きは関係しない（【4】は4本でこの4本を含まない）。

#### B卓が1件だけの理由

B卓にも2本ある（限定 hEcZKGw62pA・公開 YkDnyZIYa3c）。2本とも題名が「第一期鳳匠戦ベスト16B卓」（印を外すと同じ）なので同じ組になり、hEcZKGw62pA が完全版、YkDnyZIYa3c はその無料版として付くだけで、予定にならない（`frames += [(v, public[0] if public and v is longest else None) for v in members]`）。
