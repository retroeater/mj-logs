- `scripts/chat_ids.py`（新規）
  - `collect()`: `git log --all` のコミットのメッセージから行頭の `Chat-Ref: CHAT-<4桁>-<ID>-<数字>`（ID は `[A-Z0-9]{1,3}`、行全体で一致）を、
    `git log --all --name-only -- docs/logs` から `docs/logs/CHAT-<4桁>-<ID>-<数字>.md` と同名のフォルダ（画像を置いたもの）を拾い、
    識別子ごとに初めてと最後の日付（author date、`TZ=Asia/Tokyo` の `format-local`）を集める
  - `render()`: 見出しと説明2行、表「識別子・初めて使った日・最後に使った日」を識別子の順に。mj の SHA は中身に入れない（同じ一覧なら同じ中身になるように）
  - `publish()`: mj-logs の `chat-ids/HISTORY` の最後の版と中身が違うときだけ `chat-ids/<mj の短い SHA>.md` に書き、HISTORY に足す。10個より古いファイルは消す（guide/ と同じ KEEP）
- `scripts/sync_guides.py`: `IDS_DIR = 'chat-ids'`、`read_history()` にディレクトリの引数、`footer()` の最後に
  `- 使用済みの Chat-Ref 識別子: https://github.com/retroeater/mj-logs/blob/main/chat-ids/<名前>.md` の行（一覧が無ければ出さない）。
  既存の `FOOTER_RE`（`- ` で始まる行の並び）に合うので、`sync_logs.strip_footer()` はそのまま使える
- `.github/workflows/sync-logs.yml`: 「ログ・ガイド文書を写す・消す」の `mkdir -p mj-logs/logs` の直後（ログにリンクを付ける前）に `python3 scripts/chat_ids.py --dest mj-logs --after "$AFTER"`。cloudflare・work/ の両方で毎回走る。先頭のコメントに1項目足した
