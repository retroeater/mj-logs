### 前提（チャット側。平野さんの決定ではない。実物に合わせて変えてよい）
- 平野さんがプレビューで見た結果（2026-10-15、スクリーンショット）: サムネイル・X の写真は一覧・各話とも表示されている。崩れは見えていない
- 「再生時間」の値: チャット側が 2026-10-15 に YouTube の各動画のページから61本の長さを読み、`m:ss` のタブ区切り（動画ID・再生時間）にして平野さんに渡した。全部1時間未満（最短 8:07、最長 21:18）。平野さんが 2026-10-15 にシートに貼った。**Google スプレッドシートは `12:37` を12時37分と読むことがあるので、`m:ss` の文字・時刻の値（`0:12:37`・`12:37:00` など）のどちらで返っても読めるようにし、1分未満・1時間以上になった回があれば読み違いとみなして止まる**
- ページが YouTube の情報から使っているのは、公開日時・サムネイルの有無・再生時間の3つ（`scripts/fetch_youtube_meta.py` の docstring、チャット側が読んだ。要確認）。チャット側の案:
  - 公開日はシートの「公開日」列から取る（同じ日に公開された回は無い〈MTK-01 の JSON の61本で確かめた〉ので並びは変わらない。時刻は `VideoObject.uploadDate` にだけ出る。日付だけの形か 00:00 JST の形かは仮置き）
  - サムネイルは生成するときに `img.youtube.com` の maxres → sd → hq → mq を HEAD で確かめて選ぶ（MTK-01 で仮置きの JSON を作ったのと同じ方法。鍵は要らない。HEAD の失敗の扱いは `lib/net_retry.py` に合わせる）
  - 再生時間は「再生時間」列。空の回は再生時間を出さずに生成する（止めない）。一覧の総再生時間は、そろった回だけで出すか、全回そろったときだけ出すかを仮置きで決める
  - `data/mtsuku_youtube_meta.json` と `fetch_youtube_meta.py` の `--series mtsuku` は消す（使わなくなるため）。帰り道の生成物とワークフローの動きは変えない
- 「表示」列が無くなったので、全行を載せる。列は見出しの名前で読む（帰り道と同じ）
- 「-」は値が無いものとして扱う（チーム名が「-」の回はチーム名なし、選手名が「-」の枠はカードを出さない、団体が「-」なら括弧なし）。空欄のセルが残っていたら、どの回のどの列かをログに書く（止めない。チーム名・団体は「-」と同じに扱う）
- 各話の見出しの直し: h1 は作る人の名前と X の写真（帰り道と同じ）。チーム名は一覧のヒーローと同じく日付の行（「2025年7月13日公開・「やまだまえだ」」）に置く。`<title>`・og:title は、同じ作る人の回が複数あるので今のまま（チーム名を含む）でよいかを仮置きで決める
- 指名選手の写真カード: 最強戦の卓のページの「出場者」（`scripts/generate_saikyo_pages.py` の `build_table_page_body()`・`build_player_html()`、`.mj-saikyo-players`・`.mj-live-players`）の形を使う。「N巡目」の札は title/ の決勝ライブの札（`generate_title_pages.py` の `video_item_html()` の day_label、TP-14）と同じく写真の左上に重ねる。置く位置（例: 前後のエピソードの下・「〇〇の他のエピソード」の上）と、カードを押したときのリンク先は仮置き。勝敗の帯など最強戦に固有のものは出さない
- 写真の引き方: 最強戦と同じく、名前を「別名」で現在名に直したうえで「プロ」「連盟プロ以外」から引く（`scripts/lib/names.py` の `NameBook`、写真は SNS ブック）
- 生成を止める範囲: 作る人と指名選手（名前が「-」の枠を除く）のうち、「プロ」「連盟プロ以外」に登録が無い人、X の ID があって写真が読めない・写真の URL が無い・既定の卵型の人がいれば、全員を一覧にして止める（平野さんの決定）。X の ID が無い人は止めず、ヒーローでは名前だけ、指名選手のカードでは最強戦と同じ代替アバターにする。止める前に全員を確かめられる `--check` は帰り道と同じに持つ
- 今は「連盟プロ以外」に登録の無い人がいると見込む（チャット側の読み）。そのときは手順2・3のうち、コードとテストと文書まで進めて push し、`--check` で全員の一覧を出して止まる（ページの生成とプレビューは、平野さんが登録した後の続きの指示で行う）
- 画像未設定のチェック: `scripts/check_saikyo_unregistered.py`（`check-saikyo-unregistered.yml` が毎週動かす）に、Mつくの作る人と指名選手の節を足す（常設 issue の中に Mつくの節。書き方は仮置き）。登録が無い人（生成も止まる）と、登録はあるが SNS ブックに X の ID が無い人を分けて出す。ワークフローの YAML を変えずに足せない場合は、要る変更を報告に書く
- 公開対象の検査の許可リスト: `.github/workflows/assets-check.yml` の `allowed()` の並びに `mtsuku` を1語足す（cloudflare に入れるのに要る。MTK-01 の報告のとおり）。ワークフローの変更はこの1語だけ
- 「プロ」「連盟プロ以外」「別名」を新しいブックから読む変更（#567、未実装）や Actions の整理（WFL 系列、#564）と重なるかもしれない。下の止まる条件で確かめる

## 手順
1. 新しいシートで読む: 「Mつく」タブを見出しの名前で読む（動画ID・再生時間。「表示」は無い）。公開日・サムネイル・再生時間を上の前提のとおりシートと HEAD から取り、`data/mtsuku_youtube_meta.json` と `--series mtsuku` を消す。読んだ見出しの並び・行数・再生時間の入っている回の数と最短・最長をログに書く
2. ページの直し: 各話の見出しを作る人の名前と X の写真だけにし、チーム名を日付の行へ。ヒーロー（一覧・各話）から「選んだ選手：」の行を外す。各話に「指名選手」の節（4人の写真カード、「N巡目」の札つき）を足す。写真は「プロ」「連盟プロ以外」から引き、連盟以外の人にも出す。写真が読めない人がいれば止める（上の範囲）。`assets-check.yml` の許可リストに `mtsuku` を足し、画像未設定のチェックに Mつくの節を足す。テストを直し・足し、帰り道の生成物（`wayhome/` 以下・title/ の期のページの帰り道の節）と最強戦の生成物の差分が0であることを確かめる
3. 確かめと文書: 375px・PC 幅・1920×1080 で、一覧・最新話・最古の回・チーム名の無い回（`vSduV7-kLls`）・連盟以外の作る人の回・指名選手に連盟以外と登録の無い人がいる回を headless Chrome で見て、所見をログに書く。プレビュー（確認用 URL）を出す。報告の「判断が必要なこと」に、**「連盟プロ以外」に足す人の一覧**（「連盟プロ以外」の見出しの並び〈名前・名前かな・所属団体・所属補足〉でそのまま貼れるタブ区切りの行。所属団体の書き方は今のタブの値に合わせる。Mつくのシートの団体に「RMU?」のような確かでない値がある人は、そうと分かるように別に書く）と、**SNS ブックの【2】に X の ID が無い人の一覧**を、名前の一覧で書く。`docs/notes/` の Mつくの記録・`docs/decisions/`（MTK-01 と同じ分野のファイル）に、上の決定と仮置きを書く。#569 にコメントする

- `assets-check.yml` が origin/cloudflare で改名・移動されている（WFL 系列）: 改名先で同じ1語を足せるならそうしてよい。並びの作り方が変わっていて1語では済まないなら、その変更だけ外して報告に書く
