### 手順2: Apps Script

- ファイル: `scripts/apps_script/add_layer3_reference_columns.gs`（関数 `addLayer3ReferenceColumns`）。cloudflare へ入れた: **024e5a4b（2026-09-30 02:33:37 UTC）**。実行するまでシートは変わらない
- 【1】の見出しの確かめ（gviz、2026-09-30 02:3x UTC、14,102行）: 動画ID・種別・限定・公開範囲・公開日時・配信開始日時・長さ・タイトル・取得日時・状態・配信終了日時・配信予定開始日時・配信予定終了日時・配信状態・概要欄（15列、最後は O）。
  5つの見出し（動画ID・配信開始日時・配信予定開始日時・公開日時・タイトル）はすべてある。値の形は ZK-16 と同じ:
  公開日時 `…Z` 14,102・配信開始日時 空 10,044 / `…Z` 4,058・配信予定開始日時 空 14,061 / `…Z` 41・タイトル 空 0。動画IDは14,102本すべて11文字の YouTube の ID で、**大文字・小文字だけが違う ID の組は 0**（VLOOKUP は大文字・小文字を区別しないため確かめた）
- 作り:
  - 【3】の「動画ID」「冒頭」を見出しの名前で探す（1つずつでなければ止まる）。見出しが「参考:」で始まる列があれば止まる。記録のタブ「【3】参考の列の記録」があっても止まる
  - 【1】は5つの列だけを読む（概要欄は読まない）。見出しが1つずつでなければ止まる
  - 実行前に件数を表示し OK で進む → 「冒頭」の右に2列を挿入 → その2列の書式・入力規則を消す（「冒頭」の文字列の書式〈@〉を持ち込むと数式が文字として入るため）→ 見出しのセルに数式を置く
  - 置いた後に、動画IDのある行すべてで、数式の値（表示される値）とスクリプトが【1】から計算した値を比べ、エラー（`#` で始まる値）と食い違いを数える。先頭・末尾の3行と配信前の行（配信予定開始日時を使う行）の3行を表示し、記録のタブに数式・件数・例・食い違いの行を残す
- 数式（【3】の動画IDが A 列、【1】の最後の列が O のとき。記号は実行時に見出しから決める）:
  - 参考:配信日時:
    `={"参考:配信日時"; ARRAYFORMULA(LET(h, '【1】元データ'!A1:O1, d, '【1】元データ'!A2:O, ids, INDEX(d, 0, MATCH("動画ID", h, 0)), k, A2:INDEX(A:A, MAX(FILTER(ROW(A:A), A:A <> ""))), s1, IFERROR(VLOOKUP(k, HSTACK(ids, INDEX(d, 0, MATCH("配信開始日時", h, 0))), 2, FALSE), ""), s2, IFERROR(VLOOKUP(k, HSTACK(ids, INDEX(d, 0, MATCH("配信予定開始日時", h, 0))), 2, FALSE), ""), s3, IFERROR(VLOOKUP(k, HSTACK(ids, INDEX(d, 0, MATCH("公開日時", h, 0))), 2, FALSE), ""), v, IF(s1 <> "", s1, IF(s2 <> "", s2, s3)), IF((k = "") + (v = ""), "", TEXT((DATE(VALUE(LEFT(v, 4)), VALUE(MID(v, 6, 2)), VALUE(MID(v, 9, 2))) * 1440 + VALUE(MID(v, 12, 2)) * 60 + VALUE(MID(v, 15, 2)) + 540) / 1440, "yyyy-mm-dd hh:mm"))))}`
  - 参考:タイトル:
    `={"参考:タイトル"; ARRAYFORMULA(LET(h, '【1】元データ'!A1:O1, d, '【1】元データ'!A2:O, ids, INDEX(d, 0, MATCH("動画ID", h, 0)), k, A2:INDEX(A:A, MAX(FILTER(ROW(A:A), A:A <> ""))), IF(k = "", "", IFERROR(VLOOKUP(k, HSTACK(ids, INDEX(d, 0, MATCH("タイトル", h, 0))), 2, FALSE), ""))))}`
  - 【1】の列は数式の中で `MATCH("見出し", h, 0)` で引く（列の記号に頼らない。【1】の列の並びが変わっても引ける。範囲は実行時の【1】の最後の列まで）
  - 日時は分まで取って +540分（日本時間）し、秒は切り捨て。動画IDが空の行・【1】に無い動画IDの行は空
  - **値を出す範囲は2行目から動画IDのある最後の行まで**（`A2:INDEX(A:A, MAX(FILTER(ROW(A:A), A:A <> "")))`）。`A2:A` だとシートの最後の行まで `""` が入り、毎日の追記（values.append）が表の終わりをそこと見誤るおそれがあるため。追記で行が増えると範囲も伸びる
- 突き合わせ（数式そのものはこのセッションでは動かせないので、数式と同じ手順の JS の計算〈`expectedById()`・`toJstMinute()`〉を、別に書いた Python の計算〈zoneinfo で UTC → Asia/Tokyo〉と比べた。【1】【3】は gviz で読んだ今の値）:
  - **【3】の4,304行すべてで一致（食い違い 0）**。配信前の行（配信予定開始日時を使う行）は10行、配信開始日時が公開日時と違う行は1,229行
  - 例（動画ID | 使う【1】の値 | JS | Python | タイトル）:
    - 先頭 `P2Krcfm33Q0` | 公開日時 2014-08-15T05:37:56Z | 2014-08-15 14:37 | 2014-08-15 14:37 | 【麻雀】第31期十段戦~ベスト16Ａ卓~１回戦
    - 末尾 `lRfK1G89L-M` | 配信予定 2026-10-01T02:00:00Z | 2026-10-01 11:00 | 2026-10-01 11:00 | 【メンバー限定】第一期鳳匠戦ベスト16A・B卓
    - 配信前 `8mli8T4EKRE` | 配信予定 2026-10-02T07:00:00Z | 2026-10-02 16:00 | 2026-10-02 16:00 | 第24期プロクイーン~ベスト８Ａ卓~
    - 配信済み `xwIZG4Qdf70` | 配信開始 2023-06-04T04:57:53Z（公開日時は 19:21:40Z）| 2023-06-04 13:57 | 2023-06-04 13:57
    - 年をまたぐ例（手で与えた値）: 2026-12-31T15:30:59Z → 2027-01-01 00:30
  - 比べる関数 `compare()` は、同じ値なら 0件、`#N/A` の値を1件のエラー、違う題名を1件の食い違いとして数えた（node で確かめた）
