前提（チャット側。実物と食い違えば止まる）

* 今の `to_sheet_rows()` は知らない列に `""` を書き、`append_only_errors()` は追記した行を読み返して足した値と行全体で比べる。直さずに列を足すと、翌朝の追記の確認が失敗する。
* Sheets API で「値を送らない」セルの書き方（`null` か、範囲を分けて書くか）と、それが数式の広がりを止めないかは未確認。
