| 帯より下の行（寒色 14%）の字・順位の数字 | `#dfebf7` に 13.92・6.16 | `#1c2835` に 13.73・6.76 |
| 昇級・降級の帯の白字 | 5.18・5.10 | 同じ |
| 色ありの案のリーグの印（今の houou/ の色と字の色） | 鳳凰位 8.02・A 6.66・B 9.14・C 12.11・D 7.58・E 6.37 | 同じ |
| 見本の切り替えの字（灰色 13px、ページの地） | 6.68 | 9.50 |

灰色の字の条件（面で 7:1・ページの地で 4.5:1）は変わらず満たす。順位の数字（灰色 13px）は色付きの行の上で 6.06〜6.91（面の白地ではないので条件の外。4.5:1 は満たす）。

### 手順3: リーグの色の比較

見本の「見本: リーグの色」で切り替えた2案を、明・暗それぞれ、Chromium の `Emulation.setEmulatedVisionDeficiency`（DevTools の Emulate vision deficiencies と同じ。none・protanopia〈1型〉・deuteranopia〈2型〉・tritanopia〈3型〉・achromatopsia〈白黒〉）で撮った（写真 20〜23）。数字は、字ごとの代表の色（灰色の案は段の色、色ありの案はチップの色）を Machado（2009、強さ 1.0）の行列で変換して計算した（輝度のコントラスト比／色の差 ΔE76）。

隣り合う字の段の差（明るい配色。「輝度比/ΔE」。ΔE は 10 未満でほぼ同じ色、20 以上ではっきり違う目安）:

| 見え方 | 灰色の案 A-B・B-C・C-D・D-E | 色ありの案 A-B・B-C・C-D・D-E |
|---|---|---|
| ふつう | 1.84/17・1.47/12・1.31/9・1.34/11 | 1.37/34・1.33/27・1.60/111・2.30/68 |
| 1型 | 同じ | 1.59/20・1.43/17・1.31/110・2.08/45 |
| 2型 | 同じ | 1.28/8・1.27/9・1.81/113・2.07/45 |
| 3型 | 同じ | 1.51/33・1.36/24・1.42/69・2.05/28 |
| 白黒 | 同じ | 1.37/10・1.33/9・1.60/15・2.30/24 |

暗い配色の灰色の案（A1 を明るい灰色）: 1.47/12・1.84/17・1.52/11・1.24/6（D-E がほぼ同じ）。色ありの案は明るい配色と同じ色なので差も同じ。

選手の線と段（線は紺、下に面の色の縁を敷く）: 明るい配色で線と段の比は灰色の案 1.27〜7.11、色ありの案 1.11〜5.88（いちばん近い段とは両案とも 3:1 未満）。線と縁は 8.92（暗 8.07）で、どの見え方でも 7.8 以上。暗い配色の色ありの案は線と段が 1.03〜3.80（明るい青の線と水色・青の段が近い）。

| 項目 | 灰色の案 | 色ありの案 |
|---|---|---|
| 1. 一目で今いるリーグが分かるか | 期別の行: **読める**（印の字「C2」で読む。印の地は全リーグ同じ灰色なので、色からは分からない）。グラフ: **読みにくい**（段の右端の名前で読めるのは C1〜E3 だけ。鳳凰位〜B2 は段が細く名前を書けず、押して補う） | 期別の行: **読める**（字と色の両方。色は字ごとに同じ〈C1・C2 は同じ黄〉なので、数字は字で読む）。グラフ: **読みにくい**（色で字のまとまりは分かるが、名前は灰色の案と同じく C1〜E3 だけ） |
| 2. 同じアルファベットがまとまって見えるか | 期別の行: **読めない**（印は全部同じ灰色）。グラフ: **読みにくい**（上ほど濃い5段の灰色。A-B は差がある〈1.84/17〉が、C-D・D-E は ΔE 9〜11 でほぼ同じに見える） | 期別の行: **読める**（字ごとに同じ色）。グラフ: **読める**（赤橙・橙・黄・水色・青で、字のまとまりがはっきりしている。ただし同じ字の中の 1・2・3 の明るさの差は小さい） |
| 3. 期の行を流し見して、昇級・降級の流れがつかめるか | **読みにくい**（印の色は変わらない。昇級・降級のピルの色〈暖色・寒色〉と印の字で追う） | **読める**（字が変わる所で印の色が変わり〈C の黄 → D の水色〉、ピルの色と合わせて流れが見える） |
| 4. グラフで選手の線と段が見分けられるか | **読める**（紺の線と面の色の縁〈8.92:1〉で、どの段の上でも分かれる。段とだけ比べると、いちばん濃い段とは 1.27:1） | **読める**（同じく縁で分かれる。段とだけ比べると、青の段〈E〉とは 1.11:1 で、縁が無いと E の上では見失う） |
| 5. 暗い配色で 1〜4 が保てるか | 1・3・4 は保てる。**2 が明るい配色より悪い**（暗い地の上の暗い灰色で、D-E が ΔE 6。写真 22 の左で下半分の段がほぼ1色に見える） | 1〜4 とも保てる（段は明るい配色と同じ色）。線と段の差は小さくなる（1.03〜3.80）が、縁〈8.07:1〉で分かれる |
| 6. 色覚の多様性で 1〜4 が保てるか | 保てる（もともと色を使っていないので、どの見え方でも同じ。ピルの暖色・寒色は2型で褐色と青に見えるが、字で読める） | 1型・2型: **A・B・C がまとまって見える**（A-B・B-C が ΔE 8〜20。橙と黄が黄土色の近い色になる。写真 20 の2・3段目）。D・E と C の境はよく分かれる（ΔE 110 前後）。3型: A・B・C が桃色系、D・E が青緑系に分かれ、A-B・B-C は ΔE 24〜33 で区別できる。4 は縁で保てる |
| 7. 白黒にしたときに 1〜4 が保てるか | 保てる（もともと濃淡だけ。ただし 2 は上の「ふつう」と同じく C-D・D-E が近い） | **2 が崩れる**: 明るさが字の順に並ばない（黄の C がいちばん明るく、青の E がいちばん暗い）。A-B・B-C は ΔE 9〜10 でほぼ同じ。期別の行の印も明るさがばらばらで、字で読むことになる。4 は縁で保てる |

まとめ（推奨ではない）:
- 灰色の案で欠ける情報: 同じアルファベットのまとまり（期別の印では全く出ず、グラフでは C〜E の段の差が小さい。暗い配色では D-E がほぼ1色）と、期別の行を流し見したときのリーグの変化
- 色ありの案で欠ける情報: 1型・2型で A・B・C のまとまりの区別（橙と黄が近づく）と、白黒にしたときの明るさの順。どちらの案でも、グラフの鳳凰位〜B2 の名前は段が細くて書けず、押して補う
