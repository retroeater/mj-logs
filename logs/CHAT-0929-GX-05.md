### 手順1: 許可ルール

#### 公式ドキュメント

code.claude.com はセッションのプロキシを通って読めた（curl で `.md` 版を取得、2026-09-29）。

- https://code.claude.com/docs/en/permission-modes 「How the classifier evaluates actions」:
  「Each action goes through a fixed decision order. The first matching step wins: 1. Actions matching your allow, ask, or deny rules resolve immediately, with these exceptions: …」。
  例外は protected paths への書き込み・critical path の rm・MCP の requiresUserInteraction・per-command allowed domains・内容で当たる ask ルール・symlink の検査で、git のブランチ操作は含まれない。
  「3. Everything else goes to the classifier」。
  → **auto モードでも、allow ルールに当たる操作は分類器より先に決まる**（効かない、ではない）。
- 同じ節: auto モードに入ると広い allow ルール（`Bash(*)`、`Bash(python*)` のような interpreter のワイルドカード、パッケージマネージャの run、`Agent`、`Monitor`）は外されるが、「Narrow rules like `Bash(npm test)` stay in effect」。今回のルールは狭いものに当たる。
- https://code.claude.com/docs/en/permissions 「Bash」: 「Bash rules match the whole command text, with `*` standing in for any text.」
  「Compound commands」: 「The recognized command separators are `&&`, `||`, `;`, `|`, `|&`, `&`, and newlines. A rule must match each subcommand independently.」
  → `cd … && git checkout -b work/x origin/cloudflare | tail -1` のような複合コマンドでは、`git checkout` の部分がルールに当たっても、ほかの部分（`cd`・`tail` 等）が別に判定される。

#### 足したルール（`.claude/settings.json`、コミット db783506）

既存は `{}` だったので、次の内容にした（ほかの設定は無かった）。

```
{
  "permissions": {
    "allow": [
      "Bash(git checkout -b work/*)",
      "Bash(git checkout -B work/*)",
      "Bash(git switch -c work/*)"
    ]
  }
}
```

- **`work/` のブランチへの push のルールは足さなかった。** `*` は任意の文字列に当たるため、`Bash(git push origin work/*)` は
  `git push origin work/0929-gx:cloudflare`（cloudflare への push）にも当たる。指示の「cloudflare への push … は足さない」を優先した。
  ワイルドカードでは `:` を含む形を除けない。除くには `ask` ルール（例 `Bash(git push origin *:cloudflare*)`）を足す手があるが、
  それは cloudflare へのマージのたびに確認を出す（見ている人がいないと止まる）ので採らなかった。
  なお、この会話で work/ への push が分類器に止められたことは一度も無い（止められたのは GX-01 のブランチの作成だけ）。
- 効いたかは、このルールが cloudflare に入った後に始まるセッションで、`git checkout -b work/...` に確認が出ないかで確かめる。
  このセッションは設定を読み込み直していないので、ここでは確かめられない。GX-02 以後はルールが無くても確認は出ていない（分類器の判定は毎回同じではない）。
