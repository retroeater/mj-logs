平野さんの決定（2026-09-29）

* cloudflare への push の実行は、cloudflare の `docs/logs/` 全体と mj-logs の `logs/` を突き合わせ、中身の違うログを写し、cloudflare に無いログを消す方式に変える。取り消しや漏れがあっても、次の cloudflare への push で自動的に直るようにする。
