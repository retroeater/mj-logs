### 手順1: 本番の質問欄の5問（2026-10-24、`contest: "saikyo"`、各1回）

5問とも 200・`status: answered`。最後の応答の `remaining` は 8。
カードは、答えの文を `saikyo/ask-players.json` の名簿に当てた結果（`assets/houou_ask.js` の pickPlayers と同じ処理をローカルで実行。名簿の行の2行目をそのまま写す）。

**Q1「2025年度の最強位は？」**
- 答え: 「2025年度の最強位は桑田憲汰さんです。桑田さんは35期生で、最強位になったのは2025年度の1回です。」
- 出典: 麻雀最強戦 歴代最強位（/saikyo/years/）。時点: 決勝 2025年度まで
- カード: 桑田憲汰「3回出場（2025・2024・2023最強位）」
- 突き合わせ: **食い違う。** ランキング「最強位」は桑田憲汰 3回（2023・2024・2025）。答えは「1回」
- 原因（推定）: 引いた条件は champions の 2025〜2025 年度とみられる（ローカルの runQuery で同じ条件を引くと `terms: [2025]` だけが返る）。最強戦の答えの指示（`workers/ask/src/ask.mjs` の ANSWER_LINES.saikyo）が「最強位の回数は terms の個数」と書くため、範囲で切った terms を通算の回数として書いた。答えの下のカードは「2025・2024・2023最強位」なので、同じ画面で食い違う

**Q2「最強位をいちばん多く取ったのは？」**
- 答え: 「最強位を最も多く獲得しているのは桑田憲汰さんで、2023年・2024年・2025年の3回です。2位は瀬戸熊直樹さんの2回で、ほかに2人の選手も名前が挙がっています。」
- 出典: 麻雀最強戦 歴代最強位（/saikyo/years/）。時点: 決勝 2025年度まで
- カード: 桑田憲汰「3回出場（2025・2024・2023最強位）」、瀬戸熊直樹「16回出場（2022・2021最強位）」
- 突き合わせ: 1位・2位は合う。**「ほかに2人の選手も名前が挙がっています」が食い違う。** 最強位は12人（1回が10人、ランキング「最強位」の3位に10人が並ぶ）
- 原因（推定）: Claude に渡す事実は上位10件で切り、残りを `others: 2` で渡す（ask.mjs の answerInput、NAMES_MAX）。12人のうち名前の出ない2人を「ほかに2人」と書き、1回の10人には触れなかった

**Q3「通過率がいちばん高いのは？」**
- 答え: 「桑田憲汰さんの通過率が1.000で最も高くなっています。対象は対局数10回以上の選手に限られます。」
- 注記: ※対局数10回以上のみ。出典: 麻雀最強戦 ランキング（通過率）（/saikyo/ranking/pass-rate/）。時点: 麻雀最強戦 2026年10月18日の対局まで
- カード: 桑田憲汰「3回出場（2025・2024・2023最強位）」
- 突き合わせ: 合う（ページの1位 桑田憲汰 1.000、2位 鈴木大介 0.704）

**Q4「予選出場がいちばん多いのは？」**
- 答え: 「予選出場が最も多いのは16回で、4人が並んでいます（二階堂亜樹さん・佐々木寿人さん・瀬戸熊直樹さん）。」
- 出典: 麻雀最強戦 ランキング（予選出場）（/saikyo/ranking/appearances/）。時点: 麻雀最強戦 2026年10月18日の対局まで
- カード: 二階堂亜樹「16回出場（ファイナル 3回）」、佐々木寿人「16回出場（ファイナル 5回）」、瀬戸熊直樹「16回出場（2022・2021最強位）」
- 突き合わせ: 値・人数は合う（ページの1位は 二階堂亜樹・佐々木寿人・瀬戸熊直樹・藤崎智 の4人が16回）。**名前が3人だけで「ほか」が無く、藤崎智が抜けている**（答えでもカードでも映らない）
- 原因（推定）: tie.names は3人まで（query.mjs の TIE_NAMES = 3）。答えの指示の共通の行（ask.mjs の「人数より少なければ最後に「ほか」」）に従わず、「ほか」を付けなかった。items には4人とも入っている

**Q5「瀬戸熊直樹の最強戦の成績は？」**
- 答え: 「瀬戸熊直樹さんの最強戦の出場記録は36件です。最強位は2021年度と2022年度の2回獲得しています。そのほか、2012年度から2018年度にかけて、男子プロ代表決定戦や鉄人・新鋭のプロ代表決定戦で優勝した記録もあります。」
- 出典: 瀬戸熊直樹の成績（/saikyo/players/?name=瀬戸熊直樹）。時点: 麻雀最強戦 2026年10月18日の対局まで
- カード: 瀬戸熊直樹「16回出場（2022・2021最強位）」
- 突き合わせ: 事実は合う（対局数 36回はランキング「対局数」の2位の値。最強位 2021・2022。予選優勝は 2012 新鋭・2014 鉄人・2015・2018 男子プロ代表決定戦。2021「男子プロ一撃必殺」の優勝は挙げていないが誤りではない）。「出場記録は36件」は卓の数で、名前の下の「16回出場」と並べると読み違えうる（食い違いとしては数えない）
