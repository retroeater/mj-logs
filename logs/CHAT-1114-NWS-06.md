## 手順
1. 直し・回収（書き込みなし）・レビュー・マージ
   - CHAT-1113-NWS-05 のログの `## 報告` の状態の末尾に ` / 続き: CHAT-1114-NWS-06` を足す。#685 に着手中のコメントを書く（本文・状態・ラベルは変えない）
   - Batch の3本が終わっているかを確かめる。終わっていなければ15分おきに確かめ直してよい（合計45分まで）。それでも終わらなければ、何も変えずに止まる
   - 上の決定・前提の直し（種別 F の書き込み、新しいタブへの書き込み、号ごとの関門、裏付けの3つの表）を足し、試験を足す。`python3 -m unittest discover -s scripts/tests` を通し、自己レビュー（docs/notes/self-review.md）を受ける。2回目のレビューの後にも直しが要るときは同「収束」に従い、残った指摘が照らし合わせ・書く行・費用の判定に関わらなければレビュー済みの版をマージして進み、関わるなら止まる
   - マージ前に、作業ブランチで collect を書き込みなしで実行し、次をログに書く: 回収できた要求の数・失敗の数（号とページ）、実額（usage から。累計との合計）、読んだ表の数（号ごと）、照らし合わせの表（分け方 × 期 × リーグ）、号ごとの関門の割合、全体の割合、書く見込みの行の数（候補タブの種別 F: 最終の補完・最終の食い違い・途中経過の食い違い。新しいタブ: 途中経過の補完）、裏付けの3つの表
   - 止まる条件を踏んでいなければマージする
2. 関門と書き込み
   - 関門（決定の案B）を判定し、全体の割合・号ごとの割合・書かない号の一覧（理由つき）をログに書く
   - 候補タブと新しいタブの今の行の数、同じ（種別, 対象キー, モデル）の行の有無を確かめてから、書く。書く前と後の行の数、足した行の数（分け方 × 期）をログに書く。書いた後に読み直して、足した行が合うこと、ほかの行（ほかの系列・種別の候補）が変わっていないことを確かめる
   - 「食い違い」（最終・途中経過とも）は全件の表（期・前後・リーグ・名前・節・シートの値・ニュースの値・号・ページ・確度）をログに書く。「シートに無い」の表、号の間で値が違った組の表も全件書く
   - #685 に要約をコメントする（数はこのログの `## 経過` のどの表から引用したかを書く。#685 は閉じない）
3. 後片付け（手順2の書き込みが済んだ後にだけ行う）
   - 一度きりのスクリプト・ワークフロー・試験、`scripts/check_unused_names.py` の `NAME_RESOLVERS` の該当、`lib/sheets_write.py` の `WRITABLE` に足したタブ、docs/notes/github-actions.md の表の行と `scripts/tests/test_workflows_table.py` の該当を外し、試験を通してマージする。外すものは、足したファイル名・関数名で docs を含めて検索し、残った記述を全部直す
   - docs/decisions に、この指示の決定と、外したこと・戻し方（外す直前のコミットの SHA）を記録する
   - 環境の許可するホストから、NWS の系列で足したものを外す
   - 「判断が必要なこと」に、(1) 候補タブの種別 F の採用の進め方（食い違い・補完の件数と、平野さんの確かめの手間の見込み。チャット側が紙面を見て確かめられるよう、確かめる価値の高い行の号とページの一覧を添える） (2) 新しいタブの第17〜22期の節ごとの値の使い道（「鳳凰」の節の列を埋めるのに足りる期×リーグ×節がどれだけあるか〈号の抜けで欠ける節の一覧〉、累計から節ごとの値に直す手間、順位変動のページを広げるかどうか）を、メリット・デメリット・推奨つきで書く (3) 「タイトル」のブックの共有（前提のとおり、平野さんの報告待ち）

## 止まる条件
- Batch が終わらない（手順1の待ちの後）、回収できない、または失敗・期限切れの要求が合計 5 ページを超える（号とページの一覧を書いて止まる。一度きりのスクリプト・ワークフローは外さない）
- 実額の合計（これまでの累計・全号・読み直し）が $80 を超える、または超える見込み
- 試験が通らない、または自己レビューで残った指摘が照らし合わせ・書く行・費用の判定に関わる
- 関門: 全体の割合が 95% を下回る（何も書かず、号ごと・リーグごとの表と食い違いの全件を書いて止まる。一度きりのスクリプト・ワークフローは外さない）
- 関門で書かなかった号が1つでもある（通った号は書いたうえで、手順3の後片付けはせずに止まる。読み直すかどうかは平野さんが決める）
- 新しいタブを作れない、または同じ名前のタブがすでにあって行がある（何も書かずに止まる）
- 「鳳凰」シート・候補タブの行の数が読み直すたびに変わる、候補タブに同じ（種別 F, 対象キー, モデル「連盟ニュース」）の行がすでにある、書いた後の行の数が「書く前＋足した行の数」と合わない、またはほかの行が変わっている（件数を書いて止まる）
- 差分が次の範囲を超える: 一度きりのスクリプト・ワークフロー・試験、`scripts/check_unused_names.py` の `NAME_RESOLVERS`、`lib/sheets_write.py` の `WRITABLE`、docs/notes/github-actions.md の表と `scripts/tests/test_workflows_table.py`、docs（notes・decisions・ログ）。ページ・生成物・ほかのワークフローが変わったら止まる（マージしない）
- 未マージの work/ ブランチが、変えるファイルの同じ行・関数・節を変えている、または取り込みで衝突する（同じファイルの別の箇所の変更では止まらず、ログに書く）
- API の残高不足・認証・支出上限のエラー（そのまま書いて止まる）
- PDF・画像・記事の文章をコミット・ログ・issue に入れる必要が出た（入れずに止まる）
- マージ後の check-run の失敗が今回の変更による（無関係な失敗なら、原因を報告に書いたうえで残りの手順を進めてよい。一時的な接続の失敗は、失敗したジョブだけを1回再実行して success なら止まらない）
- cloudflare への push が権限判定で拒否された（別の手段を試さずに止まる）
