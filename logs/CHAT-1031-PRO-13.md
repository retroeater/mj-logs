### 1. 今の規則と11月分の読み取り結果

- 規則（docs/notes/dojo-guest-calendar.md と `sync_dojo_calendar._sync_image()`）: 読み取った名前が「プロ」シートの登録名（在籍 Y）と1件でも一致しなければ、`--apply` の書き込みは止まり、定期実行の自動更新も通知だけになる。新しい月は定期実行では書かず（差分と通知だけ）、書くのは「カレンダーに書き込む」を付けた手動実行だけ
- 11月分の読み取り結果: #426 の 2026-10-28 の通知（issuecomment-6458025889）に21件の全件がある。未定は 11/03・11/05・11/19 の3日で、読み取った文字はどれも「Coming soon」。残り18件は照合できている（通知の「照合できない名前」は Coming soon の3件だけ）。今朝（11/1 04:00 JST）の毎朝の実行でも11月の画像は変わっていない（run 41232112701 の dojo / sync「画像が変わっていないため通知しません」）
- 実際の画像に出た未定の語は「Coming soon」だけ（#426 の通知の全件を見た。10月以前の月に未定の日は無い）。「未定」「TBA」は出ていないので一覧に入れない（指示の前提の「実際の画像に出た語だけ」）
- 見分け方: 読み取った名前を NFKC にし、空白を除き、小文字にしたものが `UNDETERMINED_WORDS`（今は `comingsoon` だけ）に完全一致する日を未定とする（`is_undetermined()`）。部分一致や推測はしない（「Coming soon!」「Coming」も未定にしない）

### 2. 直したこと（9d7f7fe）

- `scripts/sync_dojo_calendar.py`: 読み取りの検証（`parse_entries`）の後、未定の日を分ける。未定の日は照合（照合できない名前）・追加・書き換え・削除・新規ゲスト・誕生日のどれにも使わない。書き込み済みの月では `plan_changes()` に未定の日を渡し、その日の予定は消さず、手で入れた予定との食い違いにも挙げない（画像が名前から「Coming soon」に替わっても、書いた予定は残す）。照合できない名前（未定の語でないもの）が1件でもあれば、今どおり書かずに止める
- 通知: 1行目を「読み取り N件 / 未定で飛ばした日 N件 / 照合できない名前 N件 / …」にし、「### 未定で飛ばした日（書き込みません）」に日付と読み取った文字を出す。結果の JSON に `undetermined` を足した（ワークフローの通知の手順は `summary`・`notify`・`applied`・`pending` しか読まないので、変えていない）
- 未定の日を飛ばした月は、18件を書けば「書き込み済みの月」（この同期が作った予定がある月）として扱われる。後で未定の日に名前が入った画像に差し替わると、定期実行の自動更新で足される。ただし3日まとめて入ると変更が3件で `AUTO_UPDATE_LIMIT`（3件以上は自動で更新しない）に当たり、通知だけになって保留の印が付く。そのときは入力なしの「カレンダーに書き込む」で反映する（テスト `test_書き込み済みの月で未定の日に名前が入れば足す` は1日の場合）
- テスト（`UndeterminedTest`、6件）: 未定の語と揺れ（大文字小文字・空白・全角・前後の空白）と未定にしない語（「Coming」「未定」「TBA」「福島祐一」「Coming soon!」）／#426 の11月分の読み取り結果そのままで「読み取り 21件 / 未定で飛ばした日 3件 / 照合できない名前 0件 / 既にある予定 0件 / 追加 18件」・書き込みなしでは書かない・保存した結果で `--apply` すると18件を書き Coming soon は書かない／未定と読み違い（福島祐一）が混じれば止まる／全部が未定の月は何も足さない／書き込み済みの月で未定になった日は消さない／未定の日に名前が入れば足す。**修正前のコードでは6件とも落ちる**（4件 ERROR・2件 FAIL）ことを確かめた。全体 `python3 -m unittest discover -s scripts/tests` は OK

### 3. 作業ブランチでの書き込みなしの手動実行（run 41250145214）

- 入力: apply なし（画像・月の指定なし）。引数 `--compare --state dojo-state.json --json result.json`
- 前回の状態は cloudflare の今朝の実行が保存したキャッシュ（`dojo-guest-state-41232112701`）から戻った
- 結果: 「**画像は前回の読み取りから変わっていません。何もしません。**」。Claude API は呼んでいない。#426 へのコメントは付かなかった（「画像が変わっていないため通知しません」）。テストの手順は 1,691件 OK
- **指示の前提との食い違い**: 前提は「書き込み無しの手動実行で11月分に『追加 18件・未定で飛ばした日 3件』と出る」だったが、今の同期は、画像が前回から変わっておらず保存した読み取り結果があるとき、書き込みの指定が無ければ何もせず通知もしない（docs/notes/dojo-guest-calendar.md「画像が前回から変わっておらず読み取り結果があれば、Claude API を呼ばない。書き込みの指定が無ければ何もせず通知もしない」、2026-10-02 からの規則）。保存した結果で差分だけを出す方法は今の同期に無いので、止まる条件「書き込み無しの実行の結果が『追加 18件・未定 3件』と違う」に当たる。手動実行の振る舞いを変える（書き込みなしでも保存した結果で差分を出す）のは指示の範囲の外なので、変えずに止めた
- 代わりの確かめ: #426 の11月分の読み取り結果（21件）をそのまま使ったテストで「追加 18件・未定で飛ばした日 3件」になること（上の `test_11月分は未定の3日を飛ばして18件を足す`）。数は #426 の通知（照合できた18件 + Coming soon 3件）と PRO-08 の一覧（「Coming soon」の3日を除いて18件、11/03・11/05・11/19）に一致する
