決定（平野さん、2026-09-29）

* 対象は live/・saikyo/・wayhome/・title/ の4系統。books/（書籍）は開発凍結中のため対象外（今ある共有ボタンも触らない）。
* 4系統で基本的に共通の仕様にする。
* 置き場所は本文の検索ボックス（絞り込み欄）の右（SH-01 の案2）。ナビの虫眼鏡の右ではない。

前提（チャット側。平野さんの決定ではない）

* SH-01 の調べでは、既存の共有ボタンは books/・live/・saikyo/・wayhome/（2系統）にある。チャット側は「共通の仕様にする」を、4系統の既存の共有ボタンを新しい共通部品に置き換えて1ページに1つにする、と読んでいる。既存のボタンにしか無い機能（例: 固有の文言・共有先）があれば、置き換える前にログに書き、止まる条件に従う。
* ボタンの形の案: ボタン1つを押すと小さなメニューが開き、「共有…」（Web Share API が使える環境だけ表示）・X・LINE・「リンクをコピー」を並べる。共有する URL は正規の URL（canonical があればそれ）、文言はページのタイトル。細部は既存の実装と SH-01 の手順3の案に合わせてよい。
* X・LINE は外部スクリプトを読み込まず、共有用のリンク（X の投稿画面、LINE の共有画面の URL にページの URL と文言を載せる）で作る。今の正しい URL の形は Claude Code が確かめる。外部ドメインへの依存を増やさない方針（CSP #9）と、インラインハンドラを使わない方針に従う（JS は外部ファイルで addEventListener）。
* 見出し・文言は日本語。アイコンを使う場合は、X・LINE の公式のロゴの扱いの決まりを確かめ、確かでなければ文字のボタンにする。

手順

1. 取り込みと確認: origin/cloudflare を取り込み、`git branch -r --no-merged origin/cloudflare` で live/・saikyo/・wayhome/・title/ と共通部品を触る未マージのブランチが無いか確かめる。SH-01 のログの手順2・3を読み、4系統の全階層について「系統・階層・ページ数・検索ボックスの有無・既存の共有ボタンの有無・生成元（生成スクリプト／テンプレート／直書き）」の表をログに書く。
2. 共通部品: 共有ボタンの HTML・CSS・JS を1か所にまとめ（置き場所は既存の共通部品の流儀に合わせる）、4系統の生成元から使う。既存の共有ボタンは、この部品に置き換える。
3. 検索ボックスが無いページ: 対象のうち、検索ボックスの無いページには付けず、系統・階層・件数をログに書いて報告の「判断が必要なこと」に入れる（置き場所は平野さんが決める）。
4. 生成と検証: 4系統を生成し直し、対象の全ページで共有ボタンが1つだけあること、検索ボックスの右にあること、既存の共有ボタンが残っていないことを数えて確かめる（件数をログに書く）。CLAUDE.md の検証（assets-check など）を通す。スマホ幅（約375px）とPC幅で、検索ボックスと並んだときに崩れないかを、系統ごとに代表ページ1つで確かめる（手段が無ければ未確認の項目に書く）。
5. OGP: 対象のうち `og:title`・`og:image` が無いページがあれば、系統・階層・件数をログに書く（直さない）。
6. push して Cloudflare のプレビューを出す。平野さんが見る代表ページ（系統ごとにトップと、いちばん深い階層のページ1つ）のプレビュー URL を「確認用:」の行にだけ書く（ログには書かない）。
