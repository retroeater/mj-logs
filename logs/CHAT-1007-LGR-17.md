## 目的
公開した「鳳凰戦 順位変動」（https://ryoei.pro/houou_race.html）を X で告知するための、短い動画の初版を作り、平野さんに mp4 を渡す。平野さんが見て、直すか投稿するかを決める。制作の仕組みは、タイトル戦の告知動画（docs/notes/title-pages.md「告知動画」、`scripts/promo_video/title/`）のものを使う。

### 決定（2026-10-07、平野さん）
- 「順位変動」のページの告知の X ポスト用に、15〜30秒程度のプロモーション動画を作る。「こんな感じで見られます」が伝わればよく、おもしろそうと思ってポストのリンクを押してもらえればよい
- 見本は、既定の「第43期前期鳳凰戦B1リーグ」でよい
- 音楽つき。操作デモを入れる。補足の説明が要る内容はテロップにする
- 最後は「ryoei.pro」の OGP 画像のような画面で締める（Apple のティザーのイメージ）
- 構成は次の表（チャット側の案を平野さんが OK とし、テロップ3つの文言を平野さんが直した）

| 秒（目安） | 画面 | テロップ |
|---|---|---|
| 0〜2.5 | タイトル | 「鳳凰戦 順位変動」／「リーグ戦の昇降級争いを再現」 |
| 2.5〜5 | 実画面。期・リーグを選ぶ部品を映す | 「期とリーグを選んで」 |
| 5〜6 | ▶ を押す（押した位置に印） | 「▶ で再生」 |
| 6〜13.5 | 第1節・第2節を実際の速さで。帯がすべりこみ、ポイントが動く | 「各節の結果で、順位が入れ替わる」 |
| 13.5〜18 | 残りの節を早送り | 「昇降級ボーダーの攻防」 |
| 18〜20.5 | 最終結果で止める | 「第23期〜第43期の全リーグ」 |
| 20.5〜24 | 白地に「ryoei.pro」がゆっくり現れる | なし |

- 形は縦長（1080×1920）。タイトル戦の告知動画と同じ
- 音楽は、タイトル戦の告知と同じ曲（軽快・120 BPM）を今回の長さに合わせて使う。新しい曲にするかは、初版を聞いてから決める
- 順位表に出る選手の写真・名前・ポイントは、そのまま映してよい

### 前提（チャット側。平野さんの決定ではない）
実物に合わせて変えてよく、変えたら報告に書く。
- 形式: 1080×1920・30fps・15〜30秒（目安は約24秒）・mp4（H.264、yuv420p）・音声あり（AAC）
- 秒数は目安。テロップは1つ2秒以上出す（「▶ で再生」は押す少し前から出すなどして2秒を確保する）。テロップは画面の下の端から10%以上離し（X の再生の操作部が重なるため）、順位表の見せたい所（上位と、降級の帯のあたり）を隠さない位置に置く
- 色: タイトルの画面も締めの画面も白地に黒字にする案（締めに使うサイト共通の OGP 画像が白地で、ページも白地のため。タイトル戦の告知は黒地だった）。余白を広く取り、動きは少なくする
- 締めの画面: リポジトリの `img/ogp.png`（本番の og:image。白地に「ryoei.pro」、1200×630）を使う案。1080×1920 の白地の中央に「ryoei.pro」の字だけがゆっくり現れ（1秒ほどで現れ、その後は動かさない）、ほかの文字・URL は足さない。画像の地の色と動画の地の色がずれて縁が見えないことを静止画で確かめる
- 制作の仕組み: `scripts/promo_video/title/`（setup.sh・build.sh・capture.mjs・compose.py・composition/・music.py）を読み、今回の分は `scripts/promo_video/houou_race/` に作る案。環境づくり・描画・音楽は title の分を借りるか写す。title の分の動きと出力は変えない（共通にまとめたくなったら、案を報告に書くだけにする）
- 操作デモの素材は、本番の https://ryoei.pro/houou_race.html をスマホの幅で開き、高解像度のスクリーンショットの連番で撮る（タイトル戦と同じ考え方。実時間の録画は解像度が低い）。このページは再生を時間で進める作り（1節3秒、節の間0.7秒、帯が入り終わるまで0.65秒）なので、撮る側で時計を1フレームずつ進めて撮る（Playwright の clock や CDP の仮想時間など。手段は実物で決める）。早送りの区間は、撮る側か描画側で速める（目安は3倍）。ページのコードは変えない
- ページを開くと既定で第43期・前期・B1 が出る（scripts/generate_houou_race.py の `pick_default()`）。URL のパラメータは使わない。第43期前期 B1 の人数と節の数は実物で確かめる（CHAT-1006-LGR-05 のログでは16名で、15名にアイコンのリンクがある）
- 「期とリーグを選んで」の場面: 選ぶ部品（期・前期/後期・A〜E・番号）を映し、上から順に目印で示して「選べる」ことを伝える案。表は既定のまま変えず、押すのは ▶ だけ
- 再生の場面では、節のラベルから最下位の行まで（昇級・降級の帯を含む）が1画面に入っていること。動画の枠に入らないときは、撮る画面の大きさと縮める倍率を測って決める（順位の入れ替わりと、降級の帯のあたりの両方が見えることを優先する。選手名が読めない大きさになるなら、収め方の案を報告に書いて、いちばん良いと考える形で作る）

## 手順
1. 素材を撮る。本番のページを開いて、既定が第43期・前期・B1 であること、人数・節の数・写真の無い選手の数を確かめてログに書く。前提の流れ（選ぶ部品 → ▶ → 第1節・第2節 → 残りの節 → 最終結果）を連番で撮る
2. 描画して音を付ける。決定の構成とテロップで mp4 にし、音楽を重ねる。書き出した mp4 を ffprobe で確かめ（解像度・fps・長さ・コーデック・音声トラック・サイズ）、2秒おきの静止画を自分で見て、字の欠け・折り返し・はみ出し・白いフレームが無いこと、テロップが読める大きさと長さで出ていること、締めの画面が白地に「ryoei.pro」だけであることを確かめる。だめな所は直して描画し直す（やり直しは3回まで。残った問題は報告に書く）
3. 渡して、残す。mp4 を `SendUserFile` で平野さんに送る（失敗したら別の手段を試さず、失敗の内容と受け渡しの候補を報告する）。制作に使ったスクリプトと、docs/notes/houou-race.md の「告知動画」の節を、作業ブランチにコミットして push する。#507 にコメントする
