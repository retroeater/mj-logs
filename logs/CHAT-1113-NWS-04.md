## 手順
1. 準備・dry-run・マージ
   - CHAT-1113-NWS-03 のログの `## 報告` の状態の末尾に ` / 続き: CHAT-1113-NWS-04` を足す。#408 に着手中のコメントを書く（本文・状態・ラベルは変えない）
   - live-channel-writer が「タイトル」のタブのあるブックを編集できるかを確かめる（できなければ、何も変えずに止まる）
   - 一度きりの書き込みの手段を作り、試験を足し、`python3 -m unittest discover -s scripts/tests` を通し、自己レビュー（docs/notes/self-review.md）を受ける
   - マージ前に作業ブランチで dry-run を実行し、次をログに全件の表で書く: 表1 の17期それぞれの、今のシートの日付の値・書く値・書くセルの数。候補タブで状態を変える行（採用17・却下44）の対象キー・分け方・足す備考。状態を変えない連盟ニュースの行の数（E 照合済み・E シートに無い）
   - 止まる条件を踏んでいなければマージする
2. 書き込み・再生成
   - cloudflare で dry-run をもう一度実行して数が同じことを確かめ、本実行する。同じ実行の中で読み直し、17期の日付のセルと候補タブの61行がすべて合うこと、ほかのセル・行が変わっていないことを確かめる。念のための dry-run（書くセル 0 になること）も行う
   - `regenerate-page.yml` を入力 `check` で手動実行し（対象は「タイトル」の日付を読むページ。ページ名は `python3 scripts/regenerate.py --list` で確かめる）、止まる理由があれば一覧を書いて止まる。無ければ再生成する。差分を「17期の日付で説明できるもの」と「その時点のシートのほかの変化（中身を書く）」に分けてログに書く
   - 本番の期のページを3つ以上（王位戦・新人王戦・十段戦かプロクイーンから）読み、日付が出ていることを URL とともにログに書く（UA は CLAUDE.md「判断・作業の原則」。15分たっても本番が古いままなら、判断待ちにせず「未確認の項目」に書いて先へ進む）
3. 片付け・起票
   - 読み直しで全件が合った後に、一度きりの手段（スクリプト・試験・ワークフローの入力・`WRITABLE` の「タイトル」のブックなど）を外し、試験を通してマージする。外すものは、足したファイル名・関数名で docs を含めて検索し、残った記述を全部直す。docs/decisions に、この指示の決定と、外したこと・戻し方（コミットの SHA）を記録する
   - 2位以下の順位を調べる issue を起票する（前提の案。同じ論点の open・closed の issue を先に検索する）
   - #408 に結果をコメントする（数はこのログの `## 経過` のどの表から引用したかを書く。日付が年だけの期の残りの数も、大会ごとに書く。#408 は閉じない）
   - 「判断が必要なこと」に、平野さんの手作業（「タイトル」のブックの live-channel-writer の共有を外す）を書く
