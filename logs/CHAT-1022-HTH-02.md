    1. URL・ファイル: `/saikyo/vs.html`（平らなファイル、`_redirects` 不要）→ 別案 `/saikyo/vs/`（`_redirects` に1行）・`/saikyo/h2h.html`
    2. パラメータ: `?name=A`・`?name=A,B`（規約の `name`）→ 別案 `?a=`・`?b=`
    3. ページの題名: h1「対戦成績」、`<title>`「対戦成績 | 最強戦 | ryoei.pro」、og:image はトップと同じ「麻雀最強戦」→ 別案「対戦成績（Head to Head）」
    4. データの持ち方: ページに埋め込む（255KB、データ約226KB。トップは188KB）→ 別案 JSON を別ファイルにして読み込む・相手ごとの卓の一覧を持たず JS で求める（約半分に縮む）
    5. トップの入口: 段1は出さない（`VS_PUBLIC = False`。プレビューのトップにも出ない。公開後の見た目は `top-entry-preview-390.jpg`）。置き場所は検索欄の直下の1行（題名「対戦成績」・2行目「出場者同士の勝敗と同卓の記録」）→ 別案 歴代最強位の下・プレビューの時だけ JS で出す
    6. 勝敗の表し方: 「3勝1敗2分」（0の項目も出す）→ 別案「3-1-2」・0を省く（「3勝1敗」）
    7. 優勝（決勝の通過）は通過として数える。2人の記録の結果の文字は今の対局のページと同じく各対局の決勝の通過を「優勝」と出す
    8. 未対局の卓は勝敗にも同卓回数にも入れない（次の対局の見どころだけで使う）。結果が一部だけ空の卓は、空の人を含む組だけ数えない（今のデータでは0卓）
    9. 次の対局の見どころ: 最新の年度（2026）の未対局の卓から、過去の対戦がある組を回数の多い順に10組まで（今のデータで6組）。0組のとき（オフシーズン）は節ごと隠す → 別案 「次の対局が決まると出ます」と書いて残す
    10. 候補の数: 3つとも10行まで。並びの順は見どころ → 対戦回数の多いペア → 相手の多い選手 → 別案 決定の文の順（ペア → 選手 → 見どころ）
    11. 同じ回数の並び: ペアは名前順、選手は延べ回数の多い順 → 名前順、対戦相手は回数の多い順 → 最近の同卓の順
    12. 2人の記録の並び: 新しい順（年度 → 対局日）。同じ対局の中はトップの検索と同じ ベスト8 → 決勝（その部分だけ古い順になる）→ 別案 同じ対局の中も決勝を先に
    13. 2人の記録の右端: A から見た「勝ち」（金のピル）・「負け」（灰色のピル）・「引き分け」（灰色の字）。A は URL の1人目
    14. 選手の選び方: houou/ の組み合わせの候補（読み・ローマ字）ではなく、トップの検索と同じ部分一致（最強戦のデータに読みが無いため）。候補は8人まで。選手1人を見ている間は候補が2人のページへ行く（案内「対戦相手を検索」）
    15. 画面の移り方: 候補・行を押すとページを読み直す（`?name=` のリンク。戻るボタンで戻れる）→ 別案 読み直さずに描き替える（history API）
    16. navbar には載せない（最強戦の中のページのため。#623 に書いた）
