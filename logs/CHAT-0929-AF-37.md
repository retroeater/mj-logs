    **2回まで繰り返す（最初の1回＋2回、待ちは5秒・15秒）**。HTTP の応答（urllib の `HTTPError`）とそれ以外の例外は繰り返さない。最後まで失敗したらその例外をそのまま投げる（呼び出し側の扱いを変えない）。繰り返したときは標準エラーに1行出す
  - `google_request(session, method, url)`: Google の API に **タイムアウト（接続10秒・読み取り60秒）** を渡し、**GET・HEAD だけ**上の再試行を使う。POST・PUT・DELETE（書き込み）はタイムアウトしても繰り返さず、今までどおり例外で止まる
    - 読み取り（GET）を再試行に含めた理由: 既存の `request` は HTTP の状態コード（403 レート・429・5xx）で GET も書き込みも同じく繰り返す作りで、読み取りを繰り返すことはもともと前提にある。タイムアウトだけ例外で抜けるのは、応答が無い点で 5xx と同じ性質のため
    - 60秒: 今の書き込みは 500 行ずつ・予定は1件ずつで、Google の API の応答は通常1秒前後。応答が止まったときに待ち続けないための上限で、正常な要求を切らない長さにした
