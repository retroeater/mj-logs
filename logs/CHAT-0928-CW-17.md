### 1. 公式ドキュメントと記録（2026-09-28）

`html_handling`（https://developers.cloudflare.com/workers/static-assets/routing/advanced/html-handling/ 、2026-04-23 更新）:

| 値 | 動き（`/file.html` と `/folder/index.html` がある場合） |
|---|---|
| `auto-trailing-slash`（**既定**） | `/file` → 200（file.html）、`/file.html` → 307 で `/file` へ、`/folder/` → 200（folder/index.html）、`/folder/index.html` → 307 で `/folder` へ（表の記載のまま）、`/folder` → 307 で `/folder/` へ |
| `force-trailing-slash` | `/file/`・`/folder/` だけが 200、ほかは末尾スラッシュ付きへ 307 |
| `drop-trailing-slash` | 末尾スラッシュ無しへ寄せる |
| `none`（今の設定、#89） | `/file.html` と `/folder/index.html` だけが 200。ほかは `not_found_handling` しだい |

- **ETag についての記述は html_handling のページに無い**。headers のページ（https://developers.cloudflare.com/workers/static-assets/headers/ ）は「ETag … Its value is a hash of the static asset file」を既定のヘッダとし、HTML や html_handling による例外は書いていない
- docs/notes/cloudflare.md「配信設定: html_handling・_redirects・canonical・_headers」の HTML の ETag の1文の次に、Email Address Obfuscation を 2026-09-28 に Off に戻したこと（平野さんの申告、#120 の記録と食い違っていた、workers.dev でも HTML に ETag が無く ETag とは無関係）を1行足した（コミット 2eb20edd）
