目的
#448 の3本目の仕上げ。1つの放送枠の中で回戦ごとに面子が違う枠の説明欄を、重複のない一覧にする。そのうえで、カレンダーへの同期（HC-10〜13、HC-15）を cloudflare へマージし、毎朝の実行でカレンダーが更新されるようにする。

決定（平野さん、2026-09-28）
* 公開カレンダーの見え方（HC-13 で書き込んだ142件）はこれでよい。見え方を確かめたので、マージしてよい（HC-12・13 の決定の「見え方を確かめてからマージする」）。
* 1つの枠の中で回戦ごとに面子が違うときは、重複のない一覧にすればよい（回戦ごとに ABCD と ACEF なら、【対局者】は ABCDEF）。麻雀日本シリーズなどのほか、若獅子戦のベスト16などでも起きる。
* 実況・解説でも同じことが起きるので、同じように重複のない一覧にする。

前提（チャット側。平野さんの決定ではない）
* 作業ブランチは HC-13 と同じ `work/0928-hc`。
* 並びは、概要欄に出てくる順（初めて出た順）の見込み。回戦の前置き（「25回戦：」など）は、どの行でも外す。
* 対局者・実況・解説の抜き出し（`live_extract.extract_players_and_staff()`）は /live のページの生成と共用している見込み。/live のページの出力を変えないため、まとめる処理はカレンダーの側（`scripts/lib/live_calendar.py`）に置く。共用の関数を変えないと進めないと分かったら、止まって報告する。
* マージの後は、毎朝の実行（schedule）でカレンダーへの書き込みまで行う。

手順
1. 修正: 説明欄の【対局者】【実況】【解説】を、概要欄のすべての回戦の行から集めた重複のない一覧にする（回戦の前置きは外す）。HC-13 で入れた「回戦の行が2行以上ある枠は前置きを外さない」扱いは不要になるので取り除く。テストを直して足し（ABCD と ACEF → ABCDEF、実況・解説の重複、前置きの除去、1回戦だけの枠が今と変わらないこと）、`python3 -m unittest discover -s scripts/tests` を通す。`docs/notes/yotei-sheet.md` を直す。/live のページの生成の出力が変わらないこと（共用の関数を変えていないこと）を確かめる。

2. 確かめ: 過去2年の回戦の行が2行以上ある枠（HC-13 で71件）から、麻雀日本シリーズ・若獅子戦のベスト16などを含む5件ほどの説明欄を、直した後の全文でログに書く。origin/cloudflare を取り込んでから、作業ブランチで書き込みなしの手動実行をして、作る・直す・消すの件数と、「直す」になる予定の一覧をログに書く（今日以降の枠で該当が無ければ0件の見込み）。

3. マージと反映: CLAUDE.md「ブランチ運用」のマージ手順で cloudflare へマージして push し、Workers Builds と自動で動いたワークフローの成否を確かめる。続けて、cloudflare で `update-live-channel.yml` を `calendar_apply` だけ選んで手動実行し、手順2の差分を反映する。もう一度書き込みなしで実行して、作る・直す・消すが0件であることを確かめる。/live・予定表のスプレッドシートと層1に書き込みが起きていないことを実行の出力で確かめる。#448 に結果と、次の毎朝の実行で確かめること（カレンダーの同期の成否、放送後の実際の時刻での上書き、仮の予定から枠の予定への切り替え）をコメントする。作業ブランチの片付けは CLAUDE.md の手順どおりにし、マージ後の自動処理の成否に条件づけない。
