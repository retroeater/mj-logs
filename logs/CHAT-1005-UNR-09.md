## 目的
「連盟プロ以外」の所属団体のうち、調べずに `-`（どの団体でもない）としている行を、公式サイトなどの根拠で確かめる。他団体のプロを「どの団体でもない」と登録したままにしないため。この指示は1回目で、調べた結果の一覧をログに出す所まで行う。シートへ入れるのは、一覧を見た平野さん。

### 決定（2026-10-05、平野さん）
- #500 の調査は Claude Code が行う
- 所属補足に「元連盟」「一般」などの記載がある行は調査済みなので、対象から除いてよい
- 成果物は、その団体と判断した根拠（公式サイトの URL など）つきの一覧（#500 の起票時の決定）

### 前提（チャット側。平野さんの決定ではない）
- 「連盟プロ以外」は 764行、所属団体は `-` 488・協会 110・最高位戦 100・連合 37・RMU 29（CHAT-1005-UNR-08 のログ、2026-10-05）。10/3 に足した38名（所属団体 `-`、名前は #500 の本文）は所属を調べていない
- 対象は「所属団体が `-` で、所属補足が空の行」と読んでいる。所属補足に何か書いてある行は、値が「元連盟」「一般」以外でも調査済みとして除く（除いた行の所属補足の値ごとの件数を書いて、平野さんが見られるようにする）
- 過去に、`-` の人を最高位戦・協会・RMU・麻将連合の公式サイトの選手一覧と突き合わせて埋めた作業がある（LV-20。docs/notes/live-page-design.md「1-4」）。使った一覧の URL と突き合わせの方法は、その記録（docs/logs/・git log・#362）で確かめる
- クラウドセッションの許可ドメイン（docs/notes/cloud-sessions.md「ネットワーク」）に、4団体の公式サイトは入っていないと読んでいる。読めるかどうかは実際に試して確かめる
- 結果をシートへ入れる人と期限は決まっていない。この指示では、平野さんが見て貼れる形の一覧までを作る
- 調べるのは麻雀の団体への所属だけ。それ以外の個人の情報は集めず、ログにも書かない（ログは公開される）

## 手順
1. 対象を決めて #500 に書く: 生成と同じ経路で「連盟プロ以外」を読み（2回読んで行数が同じこと）、所属団体の値ごとの件数、所属補足の値ごとの件数、対象（所属団体 `-`・所属補足が空）の件数と名前の一覧（行番号つき）を書く。#500 の本文の「未決のこと」を今日の決定で直す（調査は Claude Code、所属補足に記載のある行は対象外。残る未決はシートへ入れる人と期限）。4団体の公式サイトの選手一覧の URL を過去の記録で確かめ、それぞれ今の環境で読めるかを1回ずつ試して結果を書く。
2. 突き合わせて調べる: 読めた公式の一覧と、対象の名前を突き合わせる（空白・異体字の違いを吸収する。吸収の仕方を書く）。一覧に同じ名前があった人と、10/3 に足した38名は、1人ずつ根拠を確かめる（公式サイトの一覧・プロフィールのページを優先。無ければ大会の公式ページなどを使い、公式でない情報源にはその旨を書く。その人が出ている /live の動画の題名・概要欄・時期と合うかを見て、同名の別人でないかを確かめる）。1人ずつ調べるのは、この指示では50名まで（38名を先に。残りは件数と名前だけ書く）。あわせて、所属団体が4団体の行（276行）は、公式の一覧に今も同じ名前があるかだけを突き合わせ、無い人を一覧にする（1人ずつは調べない）。
3. 一覧を書いて止まる: ログに、調べた人ごとの表（行番号・名前・今の所属団体・今の所属補足・提案する所属団体・提案する所属補足・根拠の URL・確かさ・出ている動画ID の例1つ）を書く。確かさは「高: 公式の一覧に名前があり、動画の題名・概要欄・出場枠でも同じ団体と分かる」「中: 公式の一覧に同じ名前があるだけ」「低: 公式でない情報源だけ」「不明: 根拠が見つからない」「調べられない: 海外選手・名前の一部だけなど」の5つ。退会・移籍などで今は所属していない人の書き方は、今のシートの所属補足の例に合わせて提案し、合う例が無ければ「判断が必要なこと」に書く。表の後に「貼り付け用」として、今と違う値を提案する行だけを行番号順に（行番号・名前・所属団体・所属補足）書く。#500 に、件数のまとめとログの該当の節への案内を1件のコメントで書く。
