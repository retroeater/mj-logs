## 3. 名前の完全一致で困る場面と、固定の ID

調べた元: jpml_pros.html（「プロ」1,100名）、title/search.json（581人）、saikyo/ トップの埋め込みデータ（440人）、「別名」タブ（gviz で読んだ）、live/index.html

| 場面 | 実例（件数） | 完全一致で困ること |
|---|---|---|
| 同姓同名 | 「プロ」1,100名の中、title/ 581人、saikyo/ 440人のどれにも同じ名前は無い（0件） | 今は困らない。ただし名前で人を突き合わせる作りなので、「連盟プロ以外」に同じ名前の別人が入ると区別できない |
| 改名・訂正 | 「別名」タブ16行（登録名変更11・訂正5） | title/ は「別名」を当てて今の名前にそろえるので困らない。旧来の表（jpml_titles.html など）は旧シートの名前のままで、今の名前で `?name=` の完全一致をすると旧名の行が出ない（#222 の本文に実例）。「（当時：旧名）」の併記は #219 待ち |
| 表記ゆれ | live/ トップに同じ人が「高」6件・「髙」2件の2表記。名前に空白を含む人が3人 | 完全一致だと片方の表記しか当たらない。部分一致でも「高」と「髙」は寄らない（#415） |
| 部分一致で困る（参考） | title/ 581人のうち1人の名前が別の人の名前に含まれる。title/ の `?q=` は大会名・期・年も引くため、名前が大会名の文字に含まれる人が1人 | 1人へのリンクを部分一致で受けると、2人（または大会ページへのリンク）が出る |

- **サイト独自の選手の固定 ID は無い。** 「プロ」シートにあるのは外部サービスの ID（龍龍の ID は1,100名中844名にあり重複なし、ほかに X ID・note ID・YouTube チャンネル ID）。「連盟プロ以外」には X ID だけ
- 龍龍の ID は連盟プロの一部にしか無く、連盟プロ以外には無いため、そのままでは全員の ID にならない

| 案 | 中身 | 直すページ | 公開済みのリンクへの影響 |
|---|---|---|---|

| (B) 平野さんの案: `?q=` はゆるい検索、1人へのリンクは完全一致の別パラメータ | 例: `?q=` は今のまま、1人を指すときは `?player=<名前>` を完全一致で受ける（title/ に足し、saikyo/ の `?player=` は部分一致から完全一致へ）。旧来の表の `?name=` は今のまま（新サイト #296 で整理） | `assets/title.js`・`assets/saikyo.js`、`generate_jpml_pros.py`（リンクはそのまま `?player=`） | jpml_pros から saikyo/ への156件はフルの名前を渡しているので結果は変わらない。外から部分の名前（`?player=田` など）で来るリンクは結果が変わる。改名・表記ゆれは「別名」と正規化（#415）を当てれば吸収できる |
