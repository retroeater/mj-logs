  3. Code が勧める案: **P2（得点を中央・小数点そろえ）、順位とチップの間 0.8em**。得点の欄が通算成績の枠と同じ縦の線に来て（ずれ 0px）、小数点が全行でそろい、リーグのチップは得点の近く（P0 の 57〜85px → 23〜50px）に寄る。P3 は字の中心までそろうが、▲3桁と+2桁で小数点が行ごとにずれて数字の比較がしにくい。P1 は詰まるが得点が中央より左（−19px）に寄る
  4. 前提から変えたこと: P1 のリーグ → 得点の欄の間は目安の 1em でなく 2px（得点の欄は右寄せで字の前に空きがあり、1em を足すと 375px で収まらない）。P1〜P3 のチップ → 印の間を 0.45em → 2px（1行に収めるため）。P2 で期は左端のままにし、リーグだけを左の区画の右端に寄せた（広い画面では期とリーグの間が広がる）
  5. 仮置きの一覧（`docs/notes/houou-top.md`「仮置きの一覧」）
     - 今回（HOU-25）足した分: P1〜P3 の順位 → チップの間の候補（0.6・0.8・1em）とチップ → 印の間 2px、P2・P3 で鳳凰位の行の得点の欄を見えないまま残すこと、P1 のリーグ → 得点の欄の間 2px
     - それ以前（HOU-01〜23）の分は変えていない
