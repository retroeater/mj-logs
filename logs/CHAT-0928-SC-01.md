### 公式ドキュメントの確認（P2・S5 用）

**制約: `developers.google.com`・`support.google.com` はこのセッションのプロキシで拒否された**（WebFetch は `EGRESS_BLOCKED`、curl は `CONNECT tunnel failed, response 403`）。
以下はサブエージェントが対象ドメインに絞った WebSearch の結果の要約から得たもので、**ページ本文を読んで照合していない**。数値・文言は公式ページで確かめる必要がある。

- URL Inspection API（`urlInspection.index.inspect`、`POST https://searchconsole.googleapis.com/v1/urlInspection/index:inspect`）
  - 上限: プロパティ単位 2,000 件/日・600 件/分、プロジェクト単位 10,000,000 件/日・15,000 件/分（https://developers.google.com/webmaster-tools/limits ）
  - 返る値: `indexStatusResult`（verdict・coverageState・robotsTxtState・indexingState・lastCrawlTime・pageFetchState・googleCanonical・userCanonical・sitemap・referringUrls・crawledAs）、`richResultsResult`、`ampResult`、`mobileUsabilityResult`（モバイルユーザビリティは 2023-12 に廃止。値が返るかは未確認）。インデックス済みの版のみでライブテストは不可
  - スコープ: `webmasters` と `webmasters.readonly` のどちらでも可（inspect のリファレンス）。`fetch_gsc.py` の `webmasters.readonly` のままで足りる
  - 権限: **制限付きユーザーで inspect を呼べるかは公式の明記を確認できなかった（未確認）**。公式の手順はサービスアカウントを委任オーナーとして追加する形（https://developers.google.com/webmaster-tools/v1/prereqs ）。権限表のヘルプは https://support.google.com/webmasters/answer/7687615 が検索で出た（2451999 は開けず）
- Search Analytics API: 次元は query・page・country・device・searchAppearance・date（2025-04 に時間単位も）。rowLimit 25,000・1日・1サイト・検索タイプごと 50,000 行まで。検索タイプは web・image・video・news・discover・googleNews
- API のリソースは sites・sitemaps・searchanalytics・urlInspection.index の4つ（https://developers.google.com/webmaster-tools/v1/api_reference_index ）。
  「ページ」・リンク・クロールの統計情報・手動による対策・セキュリティの問題・拡張（動画ページを含む）に当たるリソースは索引に無い（「提供しない」の明文は未確認）
- BigQuery 一括エクスポート: 開始・停止は**プロパティのオーナーのみ**。課金を有効にした Google Cloud プロジェクトが必要（無料枠超過は有料）。
  `search-console-data-export@system.gserviceaccount.com` に BigQuery ジョブユーザー・データ編集者を付与。テーブルは `searchdata_site_impression`・`searchdata_url_impression`・`ExportLog`。
  設定後最大48時間で初回、以後毎日。**過去分は出力されない**（明文は未確認）（https://support.google.com/webmasters/answer/12918484 、https://developers.google.com/search/blog/2023/02/bulk-data-export ）
