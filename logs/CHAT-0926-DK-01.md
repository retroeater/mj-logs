### 手順3: 書き込みなしの読み取り（止まる条件に当たったので止めた）

実物で確かめた実行方法（`scripts/sync_dojo_calendar.py`）:

- 既定（オプションなし）: 連盟サイトの画像を読み、「プロ」シートの登録名と照合するだけ。カレンダーは読まない。書き込みもしない。
- `--compare`: カレンダーを読む（読み取りのみ）。ADC とカレンダーID（`--calendar-id` か `DOJO_CALENDAR_ID`）が必要。
- `--apply`: 書き込む。`--compare` が無いと付けられない。今回は使わない。
- 画像の読み取りには `ANTHROPIC_API_KEY` が必要。
- `--state` を付けない限り、「画像が前回から変わっていない」ことを理由に API を省く処理は動かない。
  つまりローカルでは、鍵さえあれば毎回 API が呼ばれる。

  (c) を取るには、同じ引数で API を直接呼ぶ使い捨てのスクリプトを書くか、ログを出す行をコードに足す必要がある。
